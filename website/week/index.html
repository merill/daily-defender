Week in brief

Defender advanced-hunting guidance shifts agent queries to unified AgentsInfo

Most updates were editorial maintenance, but several introduced concrete administrator guidance. Defender XDR documents the AIAgentsInfo-to-AgentsInfo transition and per-rule custom-detection correlation; Endpoint guidance warns that restrictive Conditional Access can disrupt Mobile TVM flows; Defender for Cloud ties recommendation exemptions to Azure CSPM assignment; and Office 365 specifies promotional bulk-mail routing when Bulk moves enabled is turned on.

  • Defender XDR · Hunting and detection
    AIAgentsInfo reference gives way to unified AgentsInfo

    The AIAgentsInfo reference page was removed as the documentation transitions to AgentsInfo. The guidance says AIAgentsInfo remains accessible until July 1, 2026 and directs administrators to update affected queries to AgentsInfo.

  • Defender XDR · Hunting and detection
    Custom-detection correlation is documented as a per-rule choice

    The updated Defender XDR guidance says custom detections are included in correlation by default. Administrators can include or exclude them per rule; there is no tenant-level custom-detection setting, and an exclusion can produce a predictable single-alert incident when no matching grouping rule applies.

  • Endpoint · Endpoint protection
    Mobile TVM guidance warns restrictive Conditional Access can disrupt flows

    The Mobile TVM service is documented for onboarding, security reporting, and iOS TVM. The guidance warns that restrictive Conditional Access policies can disrupt these flows and recommends excluding the service from those policies.

  • Defender for Cloud · Identity protection
    Azure CSPM is required when Defender for Cloud exemptions are needed

    Identity and access recommendations can appear without Azure CSPM Standard assigned, but the updated guidance says those recommendations don't support exemptions until the standard is assigned. Administrators needing exemptions should assign the Azure CSPM standard using the linked procedure.

  • Office 365 · Email and collaboration
    Guidance specifies when promotional bulk mail moves to Promotions

    The anti-spam guidance says that, as of July 2026, messages identified as bulk receive the Promotions tag. Promotional bulk messages move from Inbox to the Promotions folder only when Bulk moves enabled is turned on, regardless of BCL value.

For Defender administrators

Update affected hunting queries to AgentsInfo, review custom-detection correlation rules, audit Conditional Access policies affecting Mobile TVM, assign Azure CSPM when exemptions are required, and validate anti-spam routing expectations. The AIAgentsInfo guidance cites July 1, 2026 as its accessibility cutoff.
