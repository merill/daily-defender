Week in brief

Preview ISOC transition guidance expands as Defender lifecycle deadlines approach

New Microsoft Sentinel guidance describes moving existing deployments into the preview Integrated Security Operations Center (ISOC), alongside a tool for converting eligible analytics rules into Microsoft Defender custom detections. The period also records the planned retirement of two classic Defender for Identity alerts, deprecated Amazon Linux 2 ARM64 support for Defender for Endpoint, and a new Teams message-content hunting table in Defender for Office 365. Defender for IoT guidance moves the planned micro-agent retirement from June 1 to August 15, 2027; much of the remaining material is terminology, navigation, metadata, or documentation maintenance.

  • Sentinel · Cloud and workloads
    Preview ISOC transition guidance details workspace, scope, and billing constraints

    New Microsoft Sentinel guidance explains how an existing deployment can transition to Integrated Security Operations Center (ISOC), which remains in preview. It covers eligibility and permissions, connecting all workspaces, the irreversible tenant-wide transition scope, and changed discounts, pricing, and data benefits.

  • Sentinel · Cloud and workloads
    SOC optimization migration converts eligible Sentinel rules into custom detections

    The documented Microsoft Defender migration tool converts eligible Microsoft Sentinel analytics rules into custom detections. Original rules remain enabled during evaluation, so administrators can validate alert behavior and dependent automation before completing the migration and disabling the originals.

  • Defender XDR · Hunting and detection
    Defender for Office 365 adds Teams MessageContents to Advanced Hunting

    The new MessageContents table provides authorized security analysts with Teams message snippets and metadata for threat investigations. Rollout runs from late September through late November 2026, with access controlled by specific permissions.

  • Identity · Identity protection
    Defender for Identity will retire two classic alerts at November’s end

    The updated guidance names Suspected identity theft (pass-the-hash) and Remote code execution attempt as retiring at the end of November 2026. It points administrators to Defender for Endpoint behavioral blocking and containment and to custom detections in Advanced hunting as monitoring alternatives.

  • Endpoint · Endpoint protection
    Defender for Endpoint marks Amazon Linux 2 ARM64 support deprecated

    The prerequisites guidance states that Defender for Endpoint support for Amazon Linux 2 on ARM64 was deprecated on October 31, 2026, and removes the previous last-version and support-end details.

For Defender administrators

Before opting into ISOC, verify eligibility, permissions, workspace connections, the irreversible tenant-wide scope, and billing implications. Keep original analytics rules enabled through migration validation and check dependent automation. Identity teams should review alternatives before the end-of-November alert retirement, while Amazon Linux 2 ARM64 operators should migrate to a supported distribution. IoT owners should update lifecycle plans to August 15, 2027, and Teams-hunting access remains permission-gated.
