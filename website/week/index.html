Week in brief

Advanced Hunting APIs require migration by Jan 31 as Teams hunting expands

Microsoft is retiring the Microsoft Defender for Endpoint and Defender XDR Advanced Hunting APIs on February 1, 2027, requiring manual migration to the Microsoft Graph Security API by January 31. In parallel, Defender for Office 365 is rolling out the MessageContents table for Teams investigations, while updated guidance records material Identity sensor, macOS Device Control, and Exposure Management configuration changes.

  • Defender XDR · Hunting and detection
    MDE and Defender XDR Advanced Hunting APIs retire February 1, 2027

    Microsoft says the Microsoft Defender for Endpoint and Defender XDR Advanced Hunting APIs will retire on February 1, 2027. Organizations must manually migrate workflows to the Microsoft Graph Security API by January 31, 2027, to maintain functionality.

  • Defender XDR · Hunting and detection
    Teams investigations gain the MessageContents Advanced Hunting table

    Defender for Office 365 introduces a MessageContents table for Teams messages, allowing authorized analysts to query message snippets and metadata. Rollout runs from late September through mid-November 2026, and access requires specific permissions.

  • Identity · Identity protection
    Identity guidance sets new-workspace and government-cloud sensor limits

    Updated guidance states that v3.x sensor activation without Microsoft Defender for Endpoint is temporarily unsupported in government clouds. It also documents a preview restriction on installing v2.x sensors in new workspaces beginning in October 2026.

  • Endpoint · Endpoint protection
    macOS 101.26092.0009 release notes flag Legacy Device Control v1 retirement

    The macOS release notes add improvements to policy reliability, antivirus performance and health reporting, and EDR, while recording the retirement of Legacy Device Control v1.

  • Exposure Management · Vulnerabilities and exposure
    MAI Cyber switches to MAI-Cyber-1.1-Flash

    The MAI Cyber (Preview) scan configuration now uses MAI-Cyber-1.1-Flash instead of MAI-Cyber-1-Flash. Existing Foundry configurations are upgraded automatically, and MAI Cyber is identified as the recommended MDASH scan configuration.

For Defender administrators

Prioritize an inventory and migration plan for Advanced Hunting API workflows. Validate analyst permissions and investigation procedures for the MessageContents rollout. For Identity, plan supported v3.x onboarding for new workspaces and account for the Microsoft Defender for Endpoint requirement in government clouds. Review macOS dependencies on Legacy Device Control v1 and references to the retired MAI Cyber model name.
