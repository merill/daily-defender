Week in brief

Defender for Office 365 switches edited recipient matching to OR in December

The period’s most consequential change is a December 2026 Defender for Office 365 rollout: policies with multiple recipient types will change from Match all (AND) to Match any (OR) when modified, potentially expanding their scope. Existing policies will not be automatically converted. Most other updates were documentation clarifications, terminology changes, or refreshed procedures, with notable guidance on Sentinel playbook migration, AI Agent Runtime Protection limitations, mail-flow quarantine behavior, and Office 365 Unified RBAC prerequisites.

  • Defender XDR · General
    Multiple recipient types will use Match any after a policy modification

    Microsoft Defender for Office 365 will change recipient inclusion from Match all (AND) to Match any (OR) when multiple recipient types are specified and the policy is modified. This can expand policy scope; existing policies are not automatically converted.

  • Sentinel · Incidents and response
    Direct Sentinel analytics-rule playbook invocation is now deprecated

    Alert-trigger playbooks and their Microsoft Sentinel Alert triggers remain supported, but direct invocation from analytics rules is deprecated. The documented replacement is to configure automation rules for alerts from one or multiple analytics rules.

  • Endpoint · Endpoint protection
    AI Agent Runtime Protection flags misleading blocks and Claude Code continuation

    The runtime-protection guidance now warns that Audit mode may incorrectly report a prompt-injection block. In Block mode, Claude Code may continue processing a tool response after a reported block, and a later block cannot undo actions already completed.

  • Office 365 · Email and collaboration
    Common Attachments Filter releases may result in repeat quarantine

    Microsoft Defender for Office 365 routing guidance now says messages quarantined by the Common Attachments Filter may be quarantined again after release because they follow the return mail-flow path. Submissions to Microsoft should use the initial message version.

  • Office 365 · Email and collaboration
    Office 365 Unified RBAC guidance now requires two active toggles

    The Connection Filter Policies guidance replaces a Defender for Office 365-only prerequisite with a requirement that both the Defender for Office 365 and Exchange Online permissions toggles under Email & collaboration be Active. Related policy guidance records the same two-toggle condition.

For Defender administrators

Review threat protection policies that specify multiple recipient types before modifying them. For Sentinel, configure automation rules instead of relying on direct analytics-rule invocation for alert-trigger playbooks. When evaluating AI Agent Runtime Protection, treat Audit-mode block alerts and Claude Code Block-mode behavior cautiously. For affected Office 365 policy areas, verify that both required Email & collaboration permission toggles are Active.
