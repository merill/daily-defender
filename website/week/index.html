Week in brief

Defender XDR schedules detection-source alert tuning for October preview, November GA

The clearest product-facing change is a planned Defender XDR alert-tuning enhancement that will target individual detection sources, with public preview in mid-October 2026 and general availability in mid-November. Defender for Identity guidance now describes automatic sensor v3.x activation and Windows auditing for eligible servers, while Endpoint and Defender for Cloud updates document WSL container coverage and Azure Government SQL protection. Most remaining entries are documentation maintenance; the notable new Cloud Apps addition covers direct Entra RBAC review for service principals.

  • Defender XDR · Incidents and response
    Detection-source targeting is coming to Defender XDR alert-tuning rules

    Microsoft says the capability will enter public preview in mid-October 2026 and general availability in mid-November 2026. Existing rules remain scoped to all detection sources unless administrators update them.

  • Identity · Identity protection
    Defender for Identity guidance describes automatic sensor v3.x activation

    Eligible new Defender for Endpoint customers may receive automatic Defender for Identity sensor v3.x activation and Windows auditing. Existing Defender for Identity customers will see a portal notice before enablement, and eligible non-domain-controller AD FS, AD CS, and Microsoft Entra Connect servers are included. Administrators can review Sensor management and opt out if automatic enablement is not desired.

  • Endpoint · Endpoint protection
    Defender for Endpoint release guidance now lists WSL container support

    The updated guidance lists WSL containers (WSLc) as supported workloads and provides visibility into their activity, giving endpoint teams a documented basis for including WSLc in protection and monitoring plans.

  • Defender for Cloud · Cloud and workloads
    Defender for Cloud release notes document Azure Government SQL protection without AMA

    The enhanced agent for Defender for SQL Servers on Machines supports resource- and subscription-level enablement for SQL Server instances on Azure VMs and Azure Arc-enabled machines in Azure Government without deploying Azure Monitor Agent. Previously enabled customers must update plan configuration for automatic registration and verify instance protection; protecting additional instances may increase billing.

  • Cloud Apps · Cloud and workloads
    New Cloud Apps guidance covers direct Entra RBAC review for service principals

    The new App Governance guide explains how to filter, investigate, and assess Microsoft Entra RBAC roles assigned directly to service principals, including permissions, privilege levels, and risk signals. Access to app governance data and the required app governance role are prerequisites.

For Defender administrators

Existing Defender XDR alert-tuning rules will continue applying to all detection sources unless administrators update them. Identity administrators should review the Sensor management notice and eligibility before automatic enablement, and can select Opt out if it is not wanted. Endpoint teams can include WSLc workloads in protection planning. Previously enabled SQL customers in Azure Government must update plan configuration, verify instance protection, and account for possible additional billing. Cloud Apps reviewers need access to app governance data and the required app governance role.
