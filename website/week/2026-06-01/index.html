Microsoft Defender XDR: Retirement of in-app OS update notifications in Defender for Endpoint (iOS)

New

Microsoft Defender for Endpoint on iOS will retire in-app OS update notifications by late July 2026, shifting OS update compliance and enforcement solely to Microsoft Intune and MDM/MAM. This removes duplicate messaging, requires no immediate action, and aims to simplify management and unify compliance across services.

Microsoft Defender for Endpoint security updates move to Microsoft Update on Windows

New

Microsoft Defender for Endpoint EDR updates will move from monthly Windows security updates to Microsoft Update starting late May 2026 for Windows 10, expanding to Windows 11 and others by fall 2026. Updates won't usually require restarts. No action needed if using Microsoft Update; manual deployment requires adjustment.
