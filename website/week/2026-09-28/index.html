Week in brief

Foundational CSPM moves to opt-in while XDR readies detection-source alert tuning

Two Defender for Cloud changes carry the clearest operational weight: Foundational CSPM will be off by default for new Azure subscriptions from 27 October, while server identification and billing counts are changing. Defender XDR guidance now separates Sentinel-only custom-detection scheduling from Defender XDR lookback behavior and announces source-specific alert tuning for preview and general availability. Identity sensor v3 deployment guidance adds a version-specific Windows update prerequisite and eligibility limits; most other entries are terminology, navigation, formatting, or procedure maintenance.

  • Defender for Cloud · Cloud and workloads
    Foundational CSPM will be disabled by default on new Azure subscriptions

    Beginning 27 October 2026, new Azure subscriptions will have Foundational CSPM disabled by default. The plan remains free, while existing subscriptions and AWS and GCP environments are unaffected. Enable the plan on new subscriptions where its security recommendations and Secure Score are required.

  • Defender for Cloud · Cloud and workloads
    Defender for Cloud billing will stop counting non-server devices as Plan 1 servers

    The release notes state that Plan 1 will no longer bill desktop, workstation, and mobile devices as servers. For Plans 1 and 2, server identification will run more frequently and count deployed machines individually, which may change billed server totals.

  • Defender XDR · Hunting and detection
    Custom detection scheduling now depends on the data source

    Custom frequency from 5 minutes to 14 days is available only for rules based exclusively on Microsoft Sentinel data. Rules using Defender XDR data use fixed lookback periods tied to run frequency, ranging from 4 hours to 30 days. Administrators should verify the source and expected coverage when creating or reviewing rules.

  • Defender XDR · Incidents and response
    XDR alert tuning will target individual detection sources

    Microsoft says alert-tuning rules will be able to target specific detection sources, with public preview planned for mid-October 2026 and general availability for mid-November 2026. Existing rules will continue applying to all sources unless administrators update them; no action is needed unless finer-grained customization is wanted.

  • Identity · Architecture and deployment
    Sensor v3 deployment now has explicit update and eligibility gates

    Manual activation in preview is limited to eligible non-domain-controller AD FS, AD CS, and Microsoft Entra Connect servers without an existing sensor. A July 2026 or later Windows Server cumulative update is required before installing or upgrading to sensor version 3.0.8 or later for automatic RPC auditing on domain controllers.

For Defender administrators

From 27 October, enable Foundational CSPM on each new Azure subscription where its recommendations and Secure Score are needed, and review server classification and counting for billing. For custom detections, confirm the data source and lookback coverage; consider source-specific alert-tuning changes when preview opens. Before installing or upgrading sensor 3.0.8 or later for automatic RPC auditing on domain controllers, verify the Windows Server cumulative-update and eligibility requirements.
