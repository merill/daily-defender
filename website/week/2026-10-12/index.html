Week in brief

Defender for Identity guidance raises sensor prerequisite to September 2026 cumulative update

The week was dominated by documentation maintenance, but several updates have direct operational consequences. Defender for Identity deployment guidance replaces the July 2026 prerequisite with the September 2026 Windows Server cumulative update; Defender for Cloud documents a 250-snapshot scan-suspension threshold; and Cloud Apps retires two EWS-based anomaly detections on October 15. Advanced hunting guidance also moves agent data from AIAgentsInfo to unified AgentsInfo, while Endpoint release notes add concrete build and protection-behavior details.

  • Identity · Architecture and deployment
    Sensor v3 deployment now names the September 2026 cumulative update

    The Deploy Sensor V3 guidance replaces the July 2026 Windows Server cumulative-update prerequisite with September 2026 for sensor version 3.0.10 or later. It also clarifies that v2 migration does not automatically remove workspace DSA or gMSA configuration; select the local system account option before migrating from v2.x.

  • Defender for Cloud · Cloud and workloads
    Defender for Cloud documents a 250-snapshot suspension threshold for AWS scans

    The agentless-scanning guidance says deletion authorization failures involving 250 or more Defender-tagged snapshots suspend new scans for the affected AWS scope, while snapshots continue accruing storage charges until deleted. Ensure the scanner role has ec2:DeleteSnapshot, review AWS policy restrictions, and verify cleanup after access is restored.

  • Cloud Apps · Cloud and workloads
    Two EWS anomaly detections stop generating alerts after October 15

    The App Governance Anomaly Detection Alerts page now marks two EWS-based detections Retired as of October 15, 2026. They no longer generate alerts, so administrators should not use those detections as an alerting dependency after that date.

  • Defender XDR · Hunting and detection
    Advanced hunting guidance moves agent data from AIAgentsInfo to AgentsInfo

    The schema update describes the transition to the unified AgentsInfo table, whose coverage extends beyond Copilot Studio-specific columns. Review and update agent-related hunting queries and schema references accordingly.

  • Endpoint · Endpoint protection
    Endpoint release notes add new builds and protection-engine behavior details

    The release page now lists Platform 4.18.26090.9, Engine 1.1.26090.9, and security intelligence 1.461.1.0, along with automatic protection-engine refresh, improved update reliability, ASR path handling, and policy-exclusion retention. Review automation that uses the renamed PowerShell property ConfigurationProtection, and validate the documented protection and ASR behavior.

For Defender administrators

Prioritize Identity server readiness and migration settings; verify AWS scanner deletion permissions and clean up snapshots before the 250-snapshot threshold; remove monitoring dependencies on the retired EWS detections; update agent-related hunting queries to AgentsInfo; and review Endpoint automation for the renamed ConfigurationProtection property. The remaining changes are mainly editorial, navigational, or procedural refinements.
