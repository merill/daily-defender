Week in brief

ISOC transition guidance details tenant-wide limits, detection migration and ingestion changes

Microsoft Sentinel's move toward Integrated Security Operations Center (ISOC) was the period's substantive theme. New guidance covers tenant-wide transition decisions, analytics-rule conversion, and the work required before stopping duplicate Defender XDR ingestion. Defender XDR also documented a 90-day hunting window for eligible Microsoft 365 E5 customers and introduced Teams message content access in Advanced Hunting. Most remaining updates were navigation changes or revised preview-status wording.

  • Sentinel · Cloud and workloads
    Existing Sentinel deployments face a permanent, tenant-wide ISOC decision

    New transition guidance explains how existing Microsoft Sentinel deployments can opt into ISOC, which remains in preview. Administrators must review eligibility and permissions, connect all workspaces, and assess changed discounts, pricing, and data benefits before accepting the permanent tenant-wide transition scope.

  • Sentinel · Cloud and workloads
    SOC optimization can convert eligible analytics rules to custom detections

    The new migration procedure describes converting eligible Microsoft Sentinel analytics rules into Microsoft Defender custom detections. Original rules remain enabled during evaluation; administrators should validate the results and dependent automation before disabling the originals.

  • Sentinel · Cloud and workloads
    Stopping duplicate Defender XDR ingestion requires Advanced Hunting content updates

    New guidance says administrators should update Sentinel queries, rules, workbooks, and playbooks to use Advanced Hunting before stopping duplicate ingestion for supported Defender XDR tables. Tables with analytics retention of 180 days or more remain ingested, and dependent content should be reviewed before using Configure workspace.

  • Defender XDR · Hunting and detection
    Microsoft 365 E5 hunting lookback extends to 90 days

    Starting November 15, 2026, Microsoft 365 E5 customers can query supported Microsoft Defender XDR data for up to 90 days in Advanced Hunting. Queries covering more than 30 days expose different data-source and processed-data details.

  • Defender XDR · Hunting and detection
    Teams MessageContents table brings message snippets into Advanced Hunting

    Microsoft Defender for Office 365 introduces a MessageContents table for Teams messages, giving authorized security analysts access to message snippets and metadata for investigations. Access is controlled by specific permissions, with rollout running from late September through late November 2026.

For Defender administrators

Administrators evaluating ISOC should verify eligibility and permissions, connect all workspaces, and assess the transition's permanent scope and billing, pricing, and data effects. Before changing ingestion, update and validate dependent queries, detections, workbooks, playbooks, and permissions. Use the migration validation steps before disabling original analytics rules, and account for permission-controlled access to Teams message content.
