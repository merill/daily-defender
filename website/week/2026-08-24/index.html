Week in brief

Cloud Application Administrator support in App Governance retires September 26

Microsoft Defender for Cloud Apps will retire App Governance support for the Cloud Application Administrator role on September 26, 2026. Organizations with URBAC enabled should review assignments by September 25 and move affected administrators to supported roles such as Security Administrator. Defender XDR also announced unified identity response actions, a consolidated identity timeline, and an updated Attack Surface Reduction Rules example.

  • Defender XDR · General
    App Governance retires Cloud Application Administrator support

    Support for the Cloud Application Administrator role in Microsoft Defender for Cloud Apps App Governance retires on September 26, 2026. Where URBAC is enabled, review affected assignments by September 25 and reassign administrators to supported roles such as Security Administrator to maintain access.

  • Defender XDR · Identity protection
    Defender XDR will unify identity response actions

    A single workflow will support identity response actions across linked accounts, including disabling accounts and forcing password changes. The capability supports multiple identity systems and SaaS apps, with worldwide rollout beginning in mid-October 2026.

  • Defender XDR · Identity protection
    Identity pages gain a unified chronological timeline

    The Identity page’s Timeline tab will combine identity activity and alerts from multiple Microsoft security sources, with improved context, filtering, and automatic updates. Rollout is scheduled from mid-September through mid-October 2026, without changes to existing policies and with no enablement action required.

  • Endpoint · Vulnerabilities and exposure
    ASR configuration example uses a revised rule identifier

    The command example changes one Attack Surface Reduction rule ID from ending in `...e5` to `...e5b`. Use the updated identifier when copying the example; no required administrator action is stated beyond that usage.

For Defender administrators

Prioritize the App Governance role review before September 25. The identity timeline update requires no action, while unified response actions are scheduled to begin rolling out worldwide in mid-October 2026. Administrators copying the updated Attack Surface Reduction Rules example should use the revised rule identifier.

New
