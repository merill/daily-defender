Week in brief

Defender RBAC auto-enablement and Move to Quarantine set near-term priorities

The week’s most consequential changes affect access control and email response. Defender RBAC will auto-enable in December 2026, the Microsoft Entra Security Operator mapping will lose default access to key Defender for Office 365 controls, and Plan 2 is gaining a Move to Quarantine remediation action in late November. Most remaining updates were documentation clarifications, including sharper boundaries for local AI-agent discovery and Defender for SQL support through Azure Arc proxy.

  • Defender XDR · Identity protection
    Defender RBAC auto-enablement requires role review before activation

    Microsoft says Defender RBAC will be auto-enabled in the tenant starting December 2026. Existing roles will be imported for review, with activation occurring about 30 days after notification. Administrators can adjust roles as needed, and opt-out is available after activation; permissions for other Microsoft services remain unchanged.

  • Defender XDR · Email and collaboration
    Entra Security Operator mapping drops default MDO policy access

    Starting in December 2026, the Unified RBAC mapping for the Microsoft Entra Security Operator role will remove default access to email threat policies and the Tenant/Allow Block List. Administrators must manually assign permissions where that access needs to continue.

  • Defender XDR · Email and collaboration
    Plan 2 adds Move to Quarantine for suspicious mailbox messages

    The new remediation action moves suspicious email from user mailboxes into Defender quarantine for investigation and management. Rollout begins in late November 2026. No action is required, although Microsoft recommends reviewing applicable policies and roles.

  • Endpoint · Endpoint protection
    Local AI-agent guidance separates observation from proof of use

    Updated Defender for Endpoint guidance states that observing an agent process can create an inventory entry without a prompt or service permission, while discovery alone does not prove active use or successful access. The guidance also lists minimum Defender versions and Unified RBAC permissions for viewing inventory and the attack surface graph.

  • Defender for Cloud · Cloud and workloads
    Arc proxy SQL coverage hinges on extension version 2.0.3585.403

    Defender for Cloud release guidance records support for Azure Arc SQL Server instances with Arc proxy enabled when the Defender for SQL extension is version 2.0.3585.403. The version is available for manual update, while automatic rollout has not started.

For Defender administrators

Prioritize review of imported Defender RBAC roles before tenant activation and explicitly reassign Microsoft Entra Security Operator permissions where continued access to email threat policies or the Tenant/Allow Block List is required. No rollout action is required for Move to Quarantine, but review relevant policies and roles. For local AI-agent investigations, treat inventory as evidence that a process was observed rather than proof of active use or successful access, and verify the documented versions and permissions. For Arc SQL Server deployments, check extension versions and outbound connectivity; the supported Defender for SQL extension can be updated manually, while automatic rollout has not started.
