Week in brief

Get Vulnerability By Id leads 6 Defender updates

Week of 27 July 2026 recorded 4 updated Microsoft Defender documentation changes and 2 relevant Message Center announcements. The most active areas were Office 365, Defender XDR, Identity.

  • Endpoint · Endpoint protection
    Get Vulnerability By Id

    Updated Microsoft Defender documentation in defender-endpoint/api/get-vulnerability-by-id.md.

  • Identity · Identity protection
    Migrate from Advanced Threat Analytics (ATA) to Microsoft Defender for Identity

    Updated Microsoft Defender documentation in defender-for-identity/migrate-from-ata-overview.md.

  • Defender XDR · Endpoint protection
    Action Required: Defer Upgrade to Microsoft Defender for Endpoint on Linux Build 101.26052.0009

    The upgrade to Microsoft Defender for Endpoint on Linux build 101.26052.0009 for FIPS-enabled RHEL 8 and 9 devices has been paused due to issues. The message is now outdated and can be disregarded. No action is needed if already upgraded without problems.

  • Office 365 · Email and collaboration
    Email Authentication Arc Configure

    Updated Microsoft Defender documentation in defender-office-365/email-authentication-arc-configure.md.

  • Defender XDR · Email and collaboration
    MDO Encrypted email attachment protection

    Microsoft Defender for Office 365 will introduce an opt-in Safe Attachments policy to quarantine emails with password-protected attachments that cannot be scanned. Administrators can control release, users can self-release with passwords, and the feature supports various file types. Rollout begins August 2026 worldwide.
