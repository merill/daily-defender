Day in brief

Defender for Identity sensor v3 guidance adds tenant, update, and activation checks

Most updates were editorial or procedural, but the consequential guidance centered on Defender for Identity sensor v3 deployment and migration. Administrators now have explicit prerequisites for sensor 3.0.8 and later, a cross-tenant migration limitation, and details about automatic activation and Windows auditing. New guidance also covers direct Microsoft Entra RBAC assignments to service principals in Defender for Cloud Apps and Azure Government publishing for Sentinel CCF solutions.

  • Identity · Architecture and deployment
    Sensor 3.0.8 and later requires a July 2026-or-later Windows Server update

    The Deploy Sensor V3 guidance requires a July 2026 or later Windows Server cumulative update before installing or upgrading to sensor version 3.0.8 or later for automatic RPC auditing on domain controllers. Manual activation preview remains limited to eligible non-domain-controller AD FS, AD CS, and Microsoft Entra Connect servers without an existing sensor.

  • Identity · Identity protection
    Cross-tenant sensor v2.x-to-v3.x migration is unsupported

    The troubleshooting guidance states that migration fails when the Defender for Identity workspace and Defender for Endpoint onboarding for the same server belong to different Microsoft tenants. The server may appear ready, but sensor v3.x activation fails.

  • Identity · Identity protection
    Automatic sensor activation guidance now covers eligible non-domain controllers

    The updated What's New guidance says eligible new Defender for Endpoint customers may receive automatic Defender for Identity sensor v3.x activation and Windows auditing. Existing Defender for Identity customers receive a portal notice before these settings are enabled, and eligible non-domain-controller AD FS, AD CS, and Microsoft Entra Connect servers are covered.

  • Cloud Apps · Cloud and workloads
    Cloud Apps adds a playbook for direct Entra RBAC roles on service principals

    New guidance shows how to use Defender for Cloud Apps app governance to filter, investigate, and assess Microsoft Entra RBAC roles assigned directly to service principals, including role permissions, privilege levels, and risk signals. Access to app governance data and the required app governance role are prerequisites.

  • Sentinel · Cloud and workloads
    Sentinel publishers get Azure Government guidance for CCF solutions

    A new guide covers prerequisites, Partner Center publishing, and Azure Government endpoint updates for Sentinel CCF data connector solutions. Publishers targeting Azure Government should provide the corresponding government-cloud values and validate connector endpoints to help prevent connection failures.

Whats New

Feature updateAction required

Automatic activation applies to eligible Defender for Endpoint-onboarded domain controllers, AD FS, AD CS, and Microsoft Entra Connect servers running Windows Server 2019 or later. It activates the existing capability, does not install a separate package, and excludes servers that already have a Defender for Identity sensor.
