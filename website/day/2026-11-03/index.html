Day in brief

Microsoft Entra Security Operator loses default threat-policy and Tenant Allow/Block List access in December

Starting in December 2026, Microsoft Defender for Office 365 will update Unified RBAC mapping for the Microsoft Entra Security Operator role, removing default access to email threat policies and the Tenant Allow/Block List. A separate URBAC expansion adds email preview and download access for alerts involving potentially malicious URL clicks. Endpoint guidance also sharpens local AI-agent discovery limits and prerequisites, while Sentinel guidance documents MCP-assisted triage querying.

  • Defender XDR · Email and collaboration
    Security Operator RBAC mapping will remove default email-policy access

    Microsoft Defender for Office 365 will update the Unified RBAC mapping for the Microsoft Entra Security Operator role beginning in December 2026. Default access to email threat policies and the Tenant Allow/Block List will be removed, so organizations needing continued access must manually assign permissions.

  • Defender XDR · General
    URBAC email-content access expands to malicious URL-click alerts

    Microsoft Defender now includes alerts related to potentially malicious URL clicks in its expanded email-content permission support. Analysts with the appropriate permission can preview and download emails from four alert types.

  • Endpoint · Endpoint protection
    Local-agent inventory guidance clarifies what discovery proves

    The Defender for Endpoint guidance states that observing an agent process can create an inventory entry without a prompt or service permission, and that discovery does not prove active use or successful access. It also adds minimum Defender versions and Unified RBAC permissions for viewing inventory and the attack surface graph.

  • Endpoint · Endpoint protection
    MCP server discovery now has explicit endpoint prerequisites

    The Local Agent Discovery Overview distinguishes process-based discovery from VS Code extension collection on Windows and macOS. It states that MCP server configuration discovery requires antivirus active mode and real-time protection, and removes the macOS preview note from the guidance.

  • Sentinel · Cloud and workloads
    Sentinel guidance documents MCP-based triage collection

    The Sentinel What's New guidance now describes using the Sentinel MCP triage collection to discover data, list available Advanced Hunting tables, and run hunting queries in the built-in data lake.
