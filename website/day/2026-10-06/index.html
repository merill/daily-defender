Day in brief

Defender for Identity details sensor v3.x activation without Defender for Endpoint

The period’s strongest operational changes affect Identity onboarding, Defender for Cloud KSPM scope, and Linux golden-image provisioning. Teams meeting-reporting setup and Sentinel’s ASIM Email Event reference also gained concrete guidance. Most remaining edits are navigation, capitalization, link, and wording maintenance.

  • Identity · Identity protection
    Identity activation is limited to new sensor v3.x deployments

    The updated guidance covers sensor v3.x activation without Defender for Endpoint on eligible Windows Server 2019 or later domain controllers. It applies only to new sensor v3.x deployments; automatic sensor activation and automatic Windows auditing require an active license that includes Microsoft Defender for Identity. Verify the operating system and licensing before using the method.

  • Defender for Cloud · Cloud and workloads
    KSPM recommendations move from running containers to workload controllers

    Starting October 5, 2026, KSPM misconfiguration recommendations align with Kubernetes workload controllers rather than individual running container instances. Teams should look for findings against container deployment controllers when locating and triaging recommendations.

  • Endpoint · Endpoint protection
    Linux golden-image guidance gates Defender startup on final hostnames

    The deployment article now directs administrators to embed the tenant-specific onboarding file in the golden image, keep `mdatp` stopped during image creation, and start Defender on clones only after each final hostname is set. It also adds onboarding and health checks; image automation should protect the tenant-specific file and follow this startup sequence.

  • Office 365 · Email and collaboration
    Teams meeting reporting now has an explicit Teams admin center control

    The setup path now uses the Teams admin center’s `Allow users to report meetings` policy, while the Defender portal step remains to verify `Monitor reported items in Microsoft Teams`. Use both controls when configuring meeting-report handling.

  • Sentinel · Developer and API
    Sentinel adds a reference for normalized Email Event data

    The new ASIM reference defines email routing, authentication, delivery-outcome, and threat fields, and documents the `_Im_EmailEvent` parser, custom parser naming, and filtering parameters. It provides a common basis for normalizing and querying email data across mail servers, gateways, and inspection systems.
