Day in brief

Sentinel connector references add SilentPush and Theom, remove Red Canary listings

Sentinel reference updates add SilentPush Feeds and Theom coverage while removing Red Canary entries. The Office 365 anti-spam page also moves its stated availability expectation for features, including SOC experiences, from mid-September to the end of October.

  • Sentinel · Cloud and workloads
    Data Connectors Reference revises CrowdStrike, Pathlock, and SilentPush guidance

    The Sentinel reference now lists required CrowdStrike REST API scopes, links to upgrade notes, adds Pathlock deployment guidance, removes the Red Canary connector section, and adds SilentPush Feeds details. CrowdStrike administrators should verify the listed scopes and use the updated parser for existing queries.

  • Sentinel · Cloud and workloads
    Sentinel Tables reference adds three connector entries and removes one

    The table adds SilentPush Feeds, Theom, and Theom via the Codeless Connector Framework, while removing the Red Canary Threat Detection entry. Administrators using the reference should consult the revised table for current connector listings and table names.

  • Office 365 · Email and collaboration
    Office 365 anti-spam availability expectation moves to end of October

    The documentation now says the features, including SOC experiences, should be available in all organizations by the end of October rather than mid-September. No administrator action is stated beyond updating rollout expectations.
