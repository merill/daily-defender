Day in brief

Defender portal preview brings Azure plan management, DWU billing, and server onboarding

Defender for Cloud is the clear center of gravity: new and revised guidance describes a preview for connecting Azure commercial subscriptions or management groups, managing cloud security plans in the Defender portal, and estimating costs with Defender Workload Units (DWUs). Migration changes configuration scope, makes migrated Azure portal settings view-only, and does not preserve resource-level configurations. Supporting updates clarify tenant-wide server onboarding, broaden Defender for Identity sensor v3.x coverage, and flag an upcoming Defender for Cloud Apps permission change.

  • Defender for Cloud · Cloud and workloads
    Defender for Cloud plan management moves into a scoped portal preview

    New preview guidance covers connecting Azure subscriptions or management groups and configuring plans globally or at tenant, management-group, or subscription scope. After migration, plan settings become view-only in the Azure portal, and resource-level configurations are not preserved.

  • Defender for Cloud · Cloud and workloads
    DWU guidance adds cost estimation and post-adoption reporting

    New guidance introduces Defender Workload Units, a Cloud Security Cost Estimator, and a Cloud security cost report. It also documents updated workload measurements, plan consolidations, and DNS billing treatment under the new model.

  • Defender for Cloud · Cloud and workloads
    Direct onboarding is explicitly tenant-wide for eligible non-Azure servers

    The updated procedure states that Direct onboarding affects all eligible existing and future non-Azure servers in the same Microsoft Entra tenant; individual-server or pilot-group selection is unsupported. Administrators must verify healthy Defender for Endpoint telemetry, a matching tenant, and the required roles before enabling it.

  • Identity · Architecture and deployment
    Defender for Identity sensor v3.x expands to more Windows Server roles

    Updated guidance documents sensor v3.x onboarding with or without Defender for Endpoint for eligible Windows Server 2019 or later AD FS, AD CS, and Microsoft Entra Connect servers, extending the documented coverage beyond domain controllers.

  • Defender XDR · General
    App Governance permissions will change for three Entra roles

    Starting in mid-November 2026, Microsoft Defender for Cloud Apps will align App Governance role-based access with Defender XDR. The change affects the Cloud App Security, Compliance Administrator, and Compliance Data Administrator roles, so administrators should review and update role assignments.
