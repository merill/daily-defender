Day in brief

Defender for Identity guidance flags v3 government-cloud prerequisites and v2 sensor limits

Defender for Identity guidance now documents two deployment constraints: v3.x sensor activation without Microsoft Defender for Endpoint is temporarily unsupported in government clouds, while v2.x sensor installation in new workspaces created from October 2026 is restricted in preview. The period also adds the CloudKeyVaultEvents advanced-hunting table for Azure Key Vault activity, revises Sentinel connector status references, and expands Defender XDR role-permission guidance.

  • Identity · Identity protection
    Government-cloud v3.x sensor activation now carries a Defender for Endpoint prerequisite

    The Defender for Identity What's New guidance states that activating the v3.x sensor without Microsoft Defender for Endpoint is temporarily unsupported in government cloud environments.

  • Identity · Identity protection
    New workspaces are directed to v3.x onboarding for eligible domain controllers

    Install Sensor guidance marks the v2.x sensor restriction for new workspaces as preview. For workspaces created from October 2026, eligible Windows Server 2019 or later domain controllers are directed to the v3.x deployment guidance and onboarding package.

  • Defender XDR · Hunting and detection
    CloudKeyVaultEvents adds Azure Key Vault activity to advanced hunting

    The new Defender XDR table documents Azure Key Vault operations, access identities, request details, and operation results, with schema fields and sample queries. Queries require Microsoft Defender for Cloud.

  • Sentinel · Cloud and workloads
    Sentinel reference now labels Jira Audit and SecurityScorecard Factor deprecated

    The Sentinel Tables Connectors Reference marks the Atlassian Jira Audit and SecurityScorecard Factor connectors as deprecated. It also updates connector names and links, removes GoogleCloudSCC, adds entries, and changes availability indicators for multiple connectors.

  • Defender XDR · General
    Defender XDR RBAC guidance adds core cloud-security management permissions

    The role comparison page now lists Management permissions for reading or managing environment connections, plan enablement, and policy configuration.
