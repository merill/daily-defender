Day in brief

Defender for Office 365 rolls out promotional-mail tagging and automatic folder moves

Defender for Office 365 will label promotional emails as “promotions” and can move them automatically to a Promotions folder, learning from user actions. Separately, the Office 365 permissions documentation removes the “related to Copilot” qualifier from descriptions of Data Security AI Admin DLP permissions while retaining the exclusion for prompt and response access.

  • Defender XDR · Email and collaboration
    Promotional emails gain “promotions” labels and automatic folder handling

    Microsoft says Defender for Office 365 will tag promotional emails as “promotions” and can automatically move them to a Promotions folder. The capability learns from user actions, and users can customize handling by moving messages. Public preview starts in mid-April 2026, with general rollout completing by late 2026.

  • Office 365 · Email and collaboration
    Data Security AI Admin descriptions remove the Copilot qualifier

    The Scc Permissions page now describes Data Security AI Admins and the Data Security AI Admin role as able to edit Data Loss Prevention policies without the previous “related to Copilot” qualifier. It continues to document access to view AI content, while prompt and response access remains excluded.
