Day in brief

Sentinel details a preview SAP BTP vulnerability connector and vulnerable-app detection

The substantive change this period is a Sentinel SAP BTP solution expansion in preview: guidance now covers Application Vulnerability Report Service findings, companion analytics, and workbook content. Defender XDR also records a time-limited Advanced Hunting schema transition, while Defender for Endpoint updates macOS release guidance and clarifies offboarding behavior. Other edits mainly correct access instructions, links, naming, metadata, and notification-language references.

  • Sentinel · Cloud and workloads
    SAP BTP solution guidance documents a preview vulnerability-finding connector

    The solution overview now separates SAP BTP Application Vulnerability Report Service findings into a preview connector and adds a preview analytics rule plus an Application Vulnerabilities workbook tab with a vulnerability-posture KPI. The documented use case is to combine these findings with BTP audit activity when investigating vulnerable custom applications.

  • Defender XDR · Hunting and detection
    Advanced Hunting begins a 30-day `AadDeviceId` to `EntraIdDeviceId` transition

    The schema-change notice says `AadDeviceId` is being replaced by `EntraIdDeviceId`; the old column remains available for 30 days so administrators can update hunting queries.

  • Defender XDR · General
    Defender URBAC guidance adds delegated remote-tenant Sentinel access steps

    The updated procedure covers required permissions, role assignment, and workspace selection for delegated remote tenant groups, while retaining resource-group assignment as an option. It also separates management-plane permissions from any additional data-plane access required.

  • Endpoint · Endpoint protection
    Endpoint offboarding guidance separates automatic Azure and manual server paths

    The updated page covers Windows, Linux client and server, macOS, Android, and iOS. It distinguishes subscription-wide Azure server offboarding when Defender for Servers is turned off from manual individual-server offboarding, and states that offboarding does not uninstall the software.

  • Endpoint · Endpoint protection
    Defender for Endpoint macOS release adds EDR configuration for AI agent runtime protection

    Release 101.26082.0012 is documented with EDR support for configuring AI agent runtime protection, alongside Bluetooth permission and antivirus-health reporting improvements plus accessibility, reliability, and performance fixes.
