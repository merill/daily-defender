Day in brief

ISOC transition guidance maps Sentinel migrations, ingestion changes, and RBAC prerequisites

The 17 November set centers on a coordinated Integrated Security Operations Center (ISOC) transition package. New Sentinel guidance covers the preview opt-in for existing deployments, analytics-rule conversion, Advanced Hunting cutover, Defender RBAC mapping, and MSSP operating changes. Other updates mainly refine ISOC navigation and remove preview wording from incident-case guidance while retaining the legacy experience.

  • Sentinel · Cloud and workloads
    Existing Sentinel deployments now have a documented ISOC transition path

    A new guide identifies ISOC as being in preview and documents eligibility and permissions, connecting all workspaces, the permanent tenant-wide transition scope, and changes to discounts, pricing, and data benefits.

  • Sentinel · Cloud and workloads
    SOC optimization can convert eligible analytics rules into custom detections

    The new migration procedure explains how to convert eligible Microsoft Sentinel analytics rules, validate the results, and complete migration. Original rules remain enabled during evaluation and should be disabled only after validation.

  • Sentinel · Cloud and workloads
    Advanced Hunting is the documented prerequisite for stopping duplicate ingestion

    New guidance requires administrators to update Sentinel queries, rules, workbooks, and playbooks to use Advanced Hunting before stopping duplicate ingestion for supported Defender XDR tables. Tables with analytics retention of 180 days or more remain ingested.

  • Sentinel · Cloud and workloads
    Defender RBAC mapping is part of ISOC transition readiness

    The new permissions guide explains how to import supported Sentinel roles and assignments into Defender RBAC, activate the required Defender workloads, and validate access before transitioning or changing ingestion.

  • Sentinel · Cloud and workloads
    MSSP transitions require updates across content and operating pipelines

    New MSSP guidance covers content profiles, CI/CD pipelines, detections, workbooks, automation, delegated access, and permissions when moving customer-managed Sentinel deployments to ISOC in Microsoft Defender. MSSPs must validate access across customer tenants.
