Day in brief

Defender for Identity sensor v3 guidance shifts to September cumulative updates

This was primarily a documentation-maintenance day—22 updates and one removed page, with no new entries—but several changes have direct operational consequences. Defender for Identity guidance now centers on September 2026 Windows Server updates and clarifies sensor migration and offboarding behavior. Defender for Cloud documents an AWS scan-suspension threshold, while Defender XDR clarifies both the AIAgentsInfo-to-AgentsInfo schema transition and where DLP signals can be investigated.

  • Identity · Architecture and deployment
    Defender for Identity sensor v3 prerequisites move to September 2026 cumulative updates

    The Deploy Sensor V3 guidance replaces the July 2026 prerequisite with the September 2026 Windows Server cumulative update for sensor version 3.0.10 or later. It also clarifies that administrators should select the local system account option before v2 migration and that migration does not automatically remove workspace DSA or gMSA configuration.

  • Identity · Identity protection
    Defender for Identity guidance separates Endpoint offboarding from identity-only operation

    The FAQ states that offboarding a server from Defender for Endpoint stops Defender for Identity v3.x sensor reporting, including sensors migrated from v2.x, and does not automatically enable identity-only mode. Deployments needing identity-only protection should use the onboarding method that excludes Defender for Endpoint.

  • Defender for Cloud · Cloud and workloads
    AWS agentless scanning suspends new scans after 250 failed-deletion snapshots

    Defender for Cloud guidance says that 250 or more Defender-tagged snapshots accumulated because of deletion authorization failures suspend new scans for the affected AWS scope. The snapshots continue accruing storage charges until deleted, so administrators should verify ec2:DeleteSnapshot authorization and review AWS policy restrictions.

  • Defender XDR · Hunting and detection
    Advanced hunting transitions agent data from AIAgentsInfo to AgentsInfo

    The AIAgentsInfo reference was removed as the schema transitions to unified AgentsInfo, which expands beyond Copilot Studio-specific columns. The removed reference states that AIAgentsInfo remains accessible until July 1, 2026; affected queries should be updated to AgentsInfo.

  • Defender XDR · General
    DLP signals remain in advanced hunting rather than the incident queue

    The guidance says the built-in rule took effect in early October 2026, but DLP signals are treated as behaviors: they do not generate alerts or appear in the incident queue and remain available in advanced hunting. Investigators should use advanced hunting for these signals.
