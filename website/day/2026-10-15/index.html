Day in brief

App Governance retires two EWS-based detections effective October 15

The period's most consequential change is an App Governance retirement: two EWS-based detections are now retired and no longer generate alerts. Other substantive updates refine the documented scope of Microsoft Store vulnerability assessment, add Defender for Identity GPO risk-assessment guidance, expand the Cloud Apps migration support list, and announce localized default Mark and notify messages in Defender for Office 365.

  • Cloud Apps · Cloud and workloads
    Two EWS-based App Governance detections are now retired

    As of October 15, 2026, two EWS-based detections are marked Retired and no longer generate alerts. Cloud Apps administrators should not rely on them for detection coverage after that date.

  • Identity · Identity protection
    Defender for Identity guidance adds two GPO assessment scenarios

    The updated guidance now covers excessive local-group privileges granted by Group Policy Objects and reversible passwords stored in Group Policy Preferences. It includes the associated risks, user impact, remediation steps, and dependencies to check before making changes.

  • Vulnerability Management · General
    TVM now describes limited Store-app vulnerability coverage

    The Software Inventory page no longer labels Microsoft Store applications as Preview or lists individual supported apps. It now states that vulnerability assessment is available for a limited set of commonly used Microsoft Store applications.

  • Cloud Apps · Cloud and workloads
    Cloud Apps migration guidance adds auto-labeling and four DLP sources

    The guide now lists auto-labeling migration for SharePoint and OneDrive, plus DLP file-policy migration for Google Workspace, Box, Dropbox, and Salesforce. The previous list contained only SharePoint and OneDrive DLP migration, so administrators should use the revised support list when planning migrations.

  • Defender XDR · General
    Defender for Office 365 will localize the default notification template

    The default “Mark and notify” email template will be localized according to each user's Outlook language settings, with global rollout starting in June 2026. Message classification and custom templates remain unchanged, and no administrator action is required.
