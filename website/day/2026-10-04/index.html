Day in brief

Custom detections spell out 5-minute-to-14-day scheduling and lookback boundaries

The period focuses on guidance changes that sharpen administrator decisions. Custom-detection pages spell out the 5-minute-to-14-day custom-frequency range, the Sentinel-only data-source boundary, fixed 4-hour-to-30-day lookbacks for Defender XDR data, and Sentinel lookback limits that remain in public preview. Other meaningful updates clarify Unified RBAC coverage for identity exclusions, restrict two Cloud Apps admin roles in new configurations, and record four GA Defender for Cloud sensor builds with security and dependency fixes.

  • Defender XDR · Hunting and detection
    Custom frequency is restricted to Sentinel-only detections

    Updated Custom Detection Rules guidance says custom frequency from 5 minutes to 14 days is available only for rules based exclusively on Microsoft Sentinel data. Rules using Defender XDR data instead use fixed lookback periods tied to run frequency, ranging from 4 hours to 30 days, and cannot use custom scoping with this frequency option.

  • Sentinel · Cloud and workloads
    Sentinel guidance sets preview lookback ceilings by frequency

    The comparison guidance lists flexible and high-frequency support for Sentinel data: lookback is up to 48 hours when frequency exceeds one hour and up to 14 days when frequency is one hour or less. Lookback remains labeled public preview.

  • Defender XDR · General
    Identity-exclusion guidance covers both response products

    The updated guidance explains that identity exclusions affect automated response actions in both Defender for Identity and Defender for Endpoint. Its Unified RBAC permissions coverage now addresses both products’ data sources, role assignments, and data-source scope.

  • Cloud Apps · Cloud and workloads
    Cloud Apps admin roles are unavailable for new configurations

    App/instance admin and User group admin role assignments can no longer be used in new configurations. Existing configurations remain supported, and organizations needing these capabilities are directed to Microsoft Support.

  • Defender for Cloud · Identity protection
    Defender for Cloud records four September GA sensor builds

    The sensor changelog now lists versions 0.11.7, 0.10.10, 0.9.68, and 0.8.61 as September 2026 GA releases, each containing security vulnerability fixes and dependency updates.
