Day in brief

Defender XDR guidance details explicit per-rule controls for custom detections

The period is dominated by documentation maintenance, but four updates carry useful operational detail. Defender XDR guidance now clearly describes default correlation, per-rule exclusions, and single-alert behavior for custom detections. Separate guidance covers July 2026 bulk-mail routing, Azure CSPM prerequisites for recommendation exemptions, and Defender for Containers provisioning failures.

  • Defender XDR · Hunting and detection
    Custom detections have documented per-rule correlation controls

    The updated Defender XDR guidance states that custom detections are included in correlation by default and can be included or excluded on a per-rule basis. When a rule is excluded and no matching grouping rule applies, it produces a predictable single-alert incident. The page also states that no tenant-level custom-detection setting is available.

  • Office 365 · Email and collaboration
    Promotional bulk-mail routing is spelled out for July 2026

    The Office 365 anti-spam guidance says that, as of July 2026, messages identified as bulk receive the Promotions tag. When Bulk moves enabled is turned on, messages move from Inbox to the Promotions folder only when they are promotional in nature, regardless of BCL value.

  • Defender for Cloud · Identity protection
    Azure CSPM assignment controls exemptions for some recommendations

    Defender for Cloud guidance now explains that some identity and access recommendations can appear without the Azure CSPM standard assigned, but those recommendations do not support exemptions unless the standard is assigned. Administrators needing exemptions should assign the standard and follow the linked assignment procedure.

  • Defender for Cloud · Troubleshooting
    Defender for Containers adds EKS and Azure Arc troubleshooting paths

    The troubleshooting guidance now covers EKS provisioning failures caused by recreated IAM roles, endpoint allowlist reconciliation, and stale Azure Arc registrations. It adds diagnostic commands and resolution steps, including preserving required Defender provisioning network ranges in infrastructure automation.
