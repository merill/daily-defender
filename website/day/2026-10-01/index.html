Day in brief

Central Linux scans and Teams reporting controls get sharper Defender administrator guidance

The substantive 1 October updates are mostly documentation guidance, but several now pin down settings and behaviors relevant to administrators. Endpoint guidance covers centrally scheduled Linux antivirus scans and clarifies secure-configuration scope; Defender for Office 365 provides more precise Teams reporting setup; Sentinel references add connector and table support details. Most of the remaining Defender for Business changes refresh navigation, terminology, and procedures.

  • Endpoint · Endpoint protection
    Secure configuration guidance adds Windows Server 2022 and 2025

    The updated Endpoint guidance now includes Windows Server 2022 and Windows Server 2025 in the device requirement. It also states that local administrator-defined antivirus exclusions are not honored by default and can be enabled through Defender or Intune policy.

  • Endpoint · Endpoint protection
    Endpoint release guidance documents centrally scheduled Linux antivirus scans

    The Microsoft Defender Endpoint Releases page now documents centrally scheduled Linux antivirus scans through managed JSON and Defender Portal policies. It also adds release information covering detection of critical Node.js, Python, and Java libraries, the libcurl 8.20.0 security update, and Windows Antivirus August 2026-2 fixes.

  • Office 365 · Email and collaboration
    Teams reporting setup gains explicit portal and PowerShell destinations

    The updated Teams submissions guidance points administrators to the Teams user reported settings page and provides Exchange Online PowerShell commands for viewing and configuring report destinations: Microsoft, a reporting mailbox, or both.

  • Sentinel · Cloud and workloads
    Sentinel connector references add Meraki File Scanned data and DCR support

    The Cisco Meraki connector reference now documents File Scanned detections and the `CiscoMerakiFileScannedEvents_CL` table. It also marks the F5Telemetry LTM and RFI Playbook Alert Results tables as supported and documents workspace transform DCR support.

  • Business · Endpoint protection
    Defender for Business clarifies which policy takes effect

    The revised policy-order guidance states that only the highest-priority applicable policy is applied. Default policy priority remains fixed; newly created policies receive a priority, and moving them changes the position of default policies.
