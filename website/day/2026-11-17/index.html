Day in brief

Sentinel ISOC preview details tenant transition and analytics-rule migration paths

The period’s consequential Sentinel changes are new guidance for the preview Integrated Security Operations Center (ISOC): existing deployments can transition under an irreversible tenant-wide scope, and eligible analytics rules can be converted to Defender custom detections and validated before cutover. Other material updates cover promotional-mail handling in Defender for Office 365, Defender for Servers billing rules, and the deprecation of Defender for Endpoint support for Amazon Linux 2 ARM64. Much of the remaining update set is lower-impact Identity terminology and portal-navigation cleanup, including revised Sensor Management paths.

  • Sentinel · Cloud and workloads
    ISOC transition guidance sets an irreversible tenant-wide scope

    New Microsoft Sentinel guidance identifies ISOC as a preview capability and explains how existing deployments opt in. It calls for eligibility and permission checks, connection of all workspaces, and review of changed discounts, pricing, and data benefits; the transition is described as irreversible at tenant scope.

  • Sentinel · Cloud and workloads
    SOC optimization migration converts eligible analytics rules into custom detections

    The new migration procedure explains how to convert eligible Microsoft Sentinel analytics rules into Microsoft Defender custom detections, validate the results, and complete migration. Original rules remain enabled during evaluation and should be disabled only after alert behavior and dependent automation have been checked.

  • Defender XDR · Email and collaboration
    Defender for Office 365 rollout adds promotional-mail tagging and folder handling

    A Microsoft 365 Message Center major update says promotional messages will be tagged as “promotions” and can be moved automatically to a Promotions folder, with the system learning from user actions. The notice lists public preview beginning in mid-April 2026 and general rollout beginning in late July 2026; administrators control the settings.

  • Defender for Cloud · Cloud and workloads
    Defender for Servers billing rules account for protection and power state

    The updated Defender for Servers FAQ states that from November 1, 2026, machines are billed only when protected by Plan 1 or Plan 2 and in a billable power state. Plan 1 billing also distinguishes desktop devices from servers using operating-system and device information, with updated agent and classification rules.

  • Endpoint · Endpoint protection
    Defender for Endpoint deprecates Amazon Linux 2 ARM64 support

    The Linux prerequisites guidance states that Defender for Endpoint support for Amazon Linux 2 on ARM64 was deprecated on October 31, 2026, and removes the previous last-version and support-end details.

This period briefing was generated by AI from the tracked Microsoft Learn and Message Center changes.
