Day in brief

App Governance previews delegated NHI RBAC as classic identity alerts retire this month

Two changes carry the greatest operational weight: App Governance is scheduled to add unified Defender XDR RBAC for Non-Human Identity management in public preview from late November, while two classic Defender for Identity alerts are scheduled to retire at month-end. Defender for IoT guidance now uses August 15, 2027, instead of June 1, 2027, for the planned micro agent retirement. Most other updates refresh terminology, navigation, metadata, or references, with useful clarifications for Endpoint Performance mode and the Purview connector name.

  • Defender XDR · General
    Unified Defender XDR RBAC is coming to App Governance

    Microsoft Defender for Cloud Apps App Governance will support unified Defender XDR RBAC in public preview starting in late November 2026. Administrators will be able to assign custom roles for Non-Human Identity viewing, policy management, and service management, with rollout scheduled to complete by mid-January 2027.

  • Identity · Identity protection
    Two classic identity alerts are scheduled for month-end retirement

    The Suspected identity theft (pass-the-hash) and Remote code execution attempt classic alerts are scheduled to retire at the end of November 2026. The guidance points administrators to Defender for Endpoint behavioral blocking and containment, plus custom detections in Advanced hunting, as monitoring alternatives.

  • IoT · General
    Defender for IoT guidance moves the planned micro agent retirement date

    The documented planned retirement date for the Defender for IoT micro agent changed from June 1, 2027, to August 15, 2027. Administrators should use the revised date for deployment and lifecycle planning.

  • Endpoint · Endpoint protection
    Performance mode guidance separates PowerShell and Intune status values

    The Endpoint guidance now states that Get-MpPreference reports PerformanceModeStatus as 1 when enabled and 0 when disabled, opposite to the values used in Intune. It also directs administrators to See volumes in Windows Security to check a volume’s status.

  • Sentinel · Cloud and workloads
    The Purview connector setup guidance drops the Preview label

    The Sentinel setup page now names the connector Microsoft Purview Information Protection instead of Microsoft Purview Information Protection (Preview) and removes the preview notice. Administrators should use the revised connector name when following the instructions.
