Password protection in Microsoft Defender leads 50 Defender updates

17 March 2026 recorded 5 new, 42 updated, 2 removed Microsoft Defender documentation changes and 1 relevant Message Center announcement. The most active areas were Endpoint, Defender XDR, Identity.

  • Defender XDR · Identity protection
    Password protection in Microsoft Defender

    Added Microsoft Defender documentation in defender-xdr/identity-security/password-protection.md.

  • Defender XDR · Identity protection
    Upcoming retirement of select threat detections in Microsoft Defender for Cloud Apps

    Microsoft Defender for Cloud Apps will retire select IaaS and PaaS threat detections by mid-May 2026 due to low impact, focusing on identity-related threats. Affected alerts and policies will be removed, but historical data remains accessible. No admin action is required, though updating related processes is recommended.
