Day in brief

Secure Score will add four AI-readiness checks for device security

The period’s main product-facing change is a Microsoft Secure Score rollout for Microsoft Defender for Endpoint. Four recommendations covering TPM 2.0, VBS, HVCI, and LAPS will roll out from early to late September 2026. Most other activity was documentation maintenance, with useful exceptions covering connectivity allowlists, missing Threat Analytics reports, and isolation behavior.

  • Defender XDR · Endpoint protection
    Secure Score adds four device-security readiness recommendations

    Microsoft Secure Score will add four AI-readiness recommendations in Microsoft Defender for Endpoint, covering TPM 2.0, VBS, HVCI, and LAPS. They will roll out from early to late September 2026 and help identify and remediate devices lacking those protections; no action is required to receive them.

  • Endpoint · Endpoint protection
    Device connectivity allowlists may require Microsoft 365 Unified Domains

    The commercial standard device-connectivity guidance now says that some environments may need to allow URLs from the Microsoft 365 unified domains list in addition to the URLs in the existing table. Review the linked list when configuring or validating network allowlists.

  • Defender XDR · Endpoint protection
    Missing emailed Threat Analytics reports may be in Threat intelligence

    The Threat Analytics guidance now directs administrators to check the Threat intelligence section when an emailed threat analytics report is missing from Threat analytics.

  • Endpoint · Endpoint protection
    Automatic attack disruption can result in full isolation

    The response guidance now notes that the issue can occur when automatic attack disruption triggers full isolation. Administrators can define an isolation exclusion rule to use selective isolation instead.

  • Defender XDR · Hunting and detection
    Custom detection rules correct the ABAP audit table name

    The supported table list now spells `ABAPAuditLog_CL` correctly, fixing the missing “L.” Administrators referencing ABAP audit log data should use the corrected table name when creating custom detection rules.
