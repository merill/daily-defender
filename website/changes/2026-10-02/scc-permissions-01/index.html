Scc Permissions

2 October 2026Doc update+2 / −2 lines

In brief

The documentation now describes Data Security AI Admins and the Data Security AI Admin role as editing Data Loss Prevention policies without the previous “related to Copilot” qualifier. Access to view AI content remains documented, while prompt and response access remains excluded.

What Defender admins need to know

Administrators should use the updated descriptions when reviewing or communicating role permissions. No action is required.
