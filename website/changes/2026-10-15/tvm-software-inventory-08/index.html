General

Tvm Software Inventory

15 October 2026Doc update+4 / −17 lines

In brief

The page no longer labels Microsoft Store applications as Preview or lists individual supported apps. It now states that vulnerability assessment is available for a limited set of commonly used Microsoft Store applications.

What Defender admins need to know

Administrators should use the updated description when assessing expected coverage for Microsoft Store applications. No action is required.

Microsoft Store applications (Preview)

Defender Vulnerability Management reports vulnerabilities detected on applications installed via the Microsoft Store. CVE evidence for these applications includes the Microsoft Store tag along with a suggested query showing the vulnerable application, version, and file location.

You can manage application versions through the Microsoft Store. Don't directly access or manage app files via the file path in the WindowsApps directory, to prevent issues with the OS environment.
