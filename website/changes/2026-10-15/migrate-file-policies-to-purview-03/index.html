Migrate File Policies To Purview

15 October 2026Feature update+6 / −7 lines

In brief

The guide now lists auto-labeling migration for SharePoint and OneDrive, plus DLP file-policy migration for Google Workspace, Box, Dropbox, and Salesforce. Previously, it listed only SharePoint and OneDrive DLP migration as supported.

What Defender admins need to know

Administrators should use the updated support list when planning migrations. No action is required.
