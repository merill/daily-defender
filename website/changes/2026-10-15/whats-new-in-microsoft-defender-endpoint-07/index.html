Whats New In Microsoft Defender Endpoint

15 October 2026Generally available+8 / −3 lines

In brief

The October 2026 entry replaces the previous Preview listing for vulnerability assessment of applications installed via the Microsoft Store, including Microsoft Teams.

What Defender admins need to know

Administrators can use the documented capability to monitor vulnerabilities in Microsoft Store applications. No action is stated.

FeatureVulnerability assessment for Microsoft Store applicationsGAVulnerability assessment for applications installed via the Microsoft Store is now generally available. Defender Vulnerability Management detects supported Microsoft Store applications, adds them to the software inventory, and assesses them for vulnerabilities. Coverage is currently limited to a select set of commonly used applications. Use the Software evidence area on the software page to view the file path for the vulnerable application, along with a suggested query showing the vulnerable app, version, and file location.
