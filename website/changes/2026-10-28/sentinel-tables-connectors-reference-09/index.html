In brief

The reference now labels Atlassian Jira Audit and SecurityScorecard Factor connectors as deprecated. It also updates connector names and links, adds several connector entries, removes GoogleCloudSCC, and changes availability indicators for multiple connectors.

What Defender admins need to know

Review connector inventories and documentation references, especially where deprecated integrations or changed availability statuses are used. No administrator action or deadline is specified.
