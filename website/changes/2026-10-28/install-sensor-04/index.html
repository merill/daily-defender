Install Sensor

28 October 2026Feature update+8 / −6 lines

In brief

The installation guidance now states that the v2.x sensor restriction for new workspaces is in preview. For workspaces created from October 2026, eligible Windows Server 2019 or later domain controllers are directed to the v3.x deployment guidance and onboarding package.

What Defender admins need to know

Administrators planning new workspaces should use the v3.x onboarding guidance for eligible servers.

Tip

For eligible domain controllers running Windows Server 2019 or later, use the Defender for Identity sensor v3.x deployment guidance. The v2.x installer procedures below don't apply to v3.x. To onboard without Defender for Endpoint deployment, use the v3.x onboarding package.

The sensor v2.x installation restriction for new workspaces is in preview. For workspaces created starting in October 2026, Defender for Identity sensor v3.x is the supported onboarding option for eligible servers running Windows Server 2019 or later. You can onboard sensor v2.x only to servers running Windows Server 2016 or earlier.
