Data Collection Analyzer

4 September 2026Doc update+2 / −2 lines

In brief

The data collection analyzer table now uses updated links for MpCmdRun.exe and Endpoint DLP, and the -v entry includes additional troubleshooting examples such as Cloud Protection reporting and Platform Update failures.

What Defender admins need to know

Administrators using the analyzer have more current troubleshooting references and scenarios; no configuration change is required.
