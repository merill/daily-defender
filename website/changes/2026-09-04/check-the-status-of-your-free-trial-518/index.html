Check the status of your free trial

4 September 2026Doc update+6 / −3 lines

In brief

The page adds a prerequisite step and clarifies that the command lists Defender for Cloud pricing configurations, including each plan’s free trial status.

What Defender admins need to know

Administrators checking trial status should review the prerequisites and use the updated command guidance.

Once the usage limit is met or once the 30-day trial ends, charges begin based on the plans enabled in your environment. To learn more about these plans, their usage limits, and associated costs, see the Defender for Cloud pricing page. You can also estimate costs with the Defender for Cloud cost calculator.

If you have multiple subscriptions, each subscription has its own free trial period. You need to check the status of each subscription's free trial individually. Azure gives you a 30-day free trial every time you activate a new plan. For example, if you activate Defender for Servers, you get 30 days free. If at a later time you activate Defender for Cloud Security Posture Management (DCSPM), you get another 30 days for that plan. Amazon Web Service (AWS) gets one trial per AWS account, and Google Cloud Project getgets one trial per account or GCP project, regardless of which plan is enabled or when.

Prerequisites

Before you check your free trial status, make sure you meet the following requirements:

  • You need a Microsoft Azure subscription. If you don't have an Azure subscription, you can sign up for a free subscription.

  • You must enable Microsoft Defender for Cloud on your Azure subscription.

  1. Select PowerShell.

  2. Run the following command to checklist the Defender for Cloud pricing configurations for your subscription, including the free trial status of your free trial:each plan:

    Get-AzSecurityPricing
