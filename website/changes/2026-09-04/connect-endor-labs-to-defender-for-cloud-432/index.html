Prerequisites

  • You need a Microsoft Azure subscription. If you don't have an Azure subscription, you can sign up for an Azure free account.

  • You must enable Microsoft Defender for Cloud on your Azure subscription on your Azure subscription..

  • You must enable Defender Cloud Security Posture Management (CSPM) on your Azure subscription.

  • Connect your DevOps environments to Defender for Cloud:

    • Connect Azure DevOps organizations to Defender for Cloud
    • Connect GitHub organizations to Defender for Cloud
    • Connect GitLab groups to Defender for Cloud

  • Have an Endor Labs account. For more information, see the Endor Labs product site.

  • Have an Endor Labs Application Programming Interface (API) key with read-only permissions. For setup instructions, see Creating API keys in Endor Labs. We recommend an expiration date of 180 days.

  • Findings from Endor Labs are only shown if the corresponding repository is also connected to Defender for Cloud.

Connect Endor Labs to Defender for Cloud

To connect your Endor Labs account to Defender for Cloud:

  1. Sign in to the Azure portal at Azure portal.

  2. Navigate to Microsoft Defender for Cloud > Environment settings.
