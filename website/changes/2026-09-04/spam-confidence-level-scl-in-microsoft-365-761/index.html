Spam confidence level (SCL) in Microsoft 365

4 September 2026Doc update+26 / −23 lines

In brief

The page now explains that SCL no longer determines spam verdicts or final actions in cloud organizations. It directs admins to use header values such as CAT and DIR, while describing SCL uses for mail flow rules and on-premises Exchange.

What Defender admins need to know

Use the updated guidance when interpreting message headers or troubleshooting spam handling; no configuration change is required.
