Configure DNS servers for reverse lookup resolution for OT monitoring

Before configuring reverse DNS lookup, make sure you have:

  • An OT network sensor with OT sensor software installed and configured and activated your OT sensor.

  • Access to your OT network sensor as an Admin user. For more information, see On-premises users and roles for OT monitoring with Defender for IoT.

  • Completed the prerequisites outlined in Configure active monitoring for OT networks, and confirmed that active monitoring is right for your network.

Define DNS servers

  1. On your OT sensor console, select System settings > Network monitoring and under Active Discovery, select Reverse DNS Lookup.

  2. In the DNS reverse lookup test for server dialog, enter an address in the Lookup Address and then select Test.

Next stepsRelated content

After configuring reverse DNS lookup, you can review resolved host names in:

  • View your device inventory from a sensor console
  • View your device inventory from the Azure portal
