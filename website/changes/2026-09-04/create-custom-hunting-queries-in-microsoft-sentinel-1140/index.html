Create custom hunting queries in Microsoft Sentinel

4 September 2026Doc update+5 / −5 lines

In brief

The article now describes writing, cloning, and editing KQL-based hunting queries, clarifies the navigation sequence, and specifies that queries from content hub solutions or repositories must be edited in their original source.

What Defender admins need to know

Administrators have clearer guidance for creating and maintaining custom hunting queries; no action is required.
