Microsoft Safety Scanner Download

4 September 2026Doc update+5 / −5 lines

In brief

The page now describes using Microsoft Safety Scanner for manual malware scans and reversing changes made by identified threats. It also updates the SHA-2 requirements, troubleshooting, and malware-removal links.

What Defender admins need to know

Administrators should use the updated references when preparing devices for Safety Scanner and troubleshooting scans.
