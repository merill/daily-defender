Create Tasks Playbook

4 September 2026Doc update+3 / −3 lines

In brief

The playbook text now says the task targets the user associated with the researched malicious IP address. The document date and authoring metadata were also updated.

What Defender admins need to know

Administrators can use the revised wording to better understand the user targeted by the analyst task; no action is required.
