How Microsoft names threat actors

4 September 2026Doc update+12 / −8 lines

In brief

The page adds Frontier Blizzard, Storm-2581, and Storm-3127; updates several Storm group classifications to financially motivated; and revises links to Defender XDR threat analytics and Microsoft Graph Threat Intelligence APIs.

What Defender admins need to know

Administrators can use the updated names, classifications, and references when investigating threats; no action is required.
