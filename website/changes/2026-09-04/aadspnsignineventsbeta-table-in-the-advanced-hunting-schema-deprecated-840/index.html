AADSpnSignInEventsBeta table in the advanced hunting schema (deprecated)

4 September 2026Retirement+7 / −5 lines

In brief

The table is now documented as deprecated and will be replaced by EntraIdSpnSignInEvents on October 19, 2026. Queries using it will be migrated automatically.

What Defender admins need to know

Administrators should be aware of the upcoming table replacement; no action is stated as required.
