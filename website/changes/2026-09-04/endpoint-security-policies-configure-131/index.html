Endpoint protection

Endpoint Security Policies Configure

4 September 2026Feature update+6 / −1 lines

In brief

The documentation now states that Endpoint security policy management cannot be used on devices with an MMA-delivered sensor. On Windows 7 SP1 and Windows Server 2008 R2 SP1, only Microsoft Defender Antivirus policy is supported.

What Defender admins need to know

Admins should review affected devices and upgrade them if broader endpoint security policy management is required.
