Monitor site security for Microsoft Defender for IoT in the Defender portal

4 September 2026Doc update+5 / −5 lines

In brief

The page title now identifies Microsoft Defender for IoT in the Defender portal, and the guidance says to select a device count in the site list to view accessible device data.

What Defender admins need to know

No administrator action is required. Site totals may include inaccessible sites, while Device Inventory shows only devices the administrator can access.

Monitor site security for Microsoft Defender for IoT in the Defender portal

Microsoft Defender for IoT in the Microsoft Defender portal includes the Site security page, which offers an overview of the security state of your entire OT environment. Your organization's security team can use this page to regularly monitor the security status of your production sites.
