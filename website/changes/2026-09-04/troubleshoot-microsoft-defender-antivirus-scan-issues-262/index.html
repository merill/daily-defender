Troubleshoot Microsoft Defender Antivirus scan issues

4 September 2026Doc update+5 / −2 lines

In brief

The documentation now explains that enabling Disable Catchup Full Scan disables catch-up scans after missed scheduled full scans, while disabling it enables them.

What Defender admins need to know

Administrators can interpret this setting correctly when troubleshooting scan configuration and performance issues.
