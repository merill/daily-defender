Manage EIoT monitoring support | Microsoft Defender for IoT

4 September 2026Doc update+17 / −17 lines

In brief

The page adds guidance for calculating detected devices for standalone licensing and warns that disabling Enterprise IoT security stops all purpose-built alerts, vulnerabilities, and recommendations. It also clarifies cancellation steps for legacy plan customers.

What Defender admins need to know

Administrators should review the warning before disabling Enterprise IoT monitoring and use the clarified device-count guidance when assessing licensing needs.
