Overview of Defender for Open-Source Relational Databases

4 September 2026Feature update+8 / −4 lines

In brief

The documentation now links to the multicloud workload protection support matrix, describes Amazon RDS support without the preview label, and states that supported RDS databases include sensitive data discovery.

What Defender admins need to know

Review the updated coverage details and support matrix when assessing protection for AWS RDS workloads.

Defender for Open-Source Relational Databases is supported on platform as a service (PaaS) environments for Azure and Amazon Web Services (AWS). It isn't supported on Azure Arc-enabled machines. For more information about availability, see Defender for Cloud support matrices for Azure commercial/other clouds.

For a summary of AWS and GCP workload coverage by plan, see the multicloud workload protection support matrix.

This plan brings threat protections for the following open-source relational databases on Azure.

Azure Database for PostgreSQL

Amazon RDS

Amazon Relational Database Service (RDS) instances on AWS (preview) support:

  • Aurora PostgreSQL
  • Aurora MySQL

Benefits

Defender for Cloud provides multicloud alerts on anomalous activities so that you can detect potential threats and respond to them as they occur. For supported Amazon RDS databases, the plan also includes sensitive data discovery. For more information, see Enable Defender for open-source relational databases on Amazon Web Services.

When you enable this plan, Defender for Cloud provides alerts when it detects anomalous database access and query patterns, along with suspicious database activities. The alerts include:
