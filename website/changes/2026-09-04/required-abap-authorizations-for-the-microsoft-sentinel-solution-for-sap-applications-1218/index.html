Required ABAP authorizations for the Microsoft Sentinel solution for SAP applications

4 September 2026Doc update+29 / −190 lines

In brief

The article now documents ABAP authorizations for the SAP account used by the Microsoft Sentinel agentless data connector. It points administrators to the MSFTSEN_SENTINEL_READER role file and removes the former per-log authorization tables and responder-role reference.

What Defender admins need to know

Use the reader role file or the consolidated authorization list when creating or reviewing the SAP connector account. No mandatory administrator action is stated.

Required ABAP authorizations

This article lists the ABAP authorizations required to ensure thatfor the SAP user account used by the Microsoft Sentinel's SAP agentless data connector can correctly retrieve logs from the SAP systems.connector.

The following tables group the required authorizations by purpose. You only need the authorizations that are listed for the kinds of logs you want to bring into Microsoft Sentinel.

  • To create a role with all the required authorizations, load the role authorizations from the /MSFTSEN/SENTINEL_RESPONDERMSFTSEN_SENTINEL_READER file.
  • If needed, you can remove the user role and optional CRs.
