Stop SAP data collection

4 September 2026Doc update+20 / −32 lines

In brief

The article now distinguishes temporary stops, by pausing the SAP Cloud Integration Data Collector flow, from permanent stops, which involve removing SAP systems, undeploying the flow, and reversing SAP-side configuration. Optional cleanup of related Azure resources is also documented.

What Defender admins need to know

Administrators stopping an agentless SAP integration should follow these updated procedures instead of the previous container-based steps.
