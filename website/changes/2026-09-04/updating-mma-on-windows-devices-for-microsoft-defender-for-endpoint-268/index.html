Updating MMA on Windows devices for Microsoft Defender for Endpoint

  • If you've determined that you aren't using the MMA for Defender for Endpoint, or you've already updated your agent, no other steps are needed.

!Important

Defender for Endpoint devices running Windows 8.1 are still supported and remain dependent on MMA.

Azure Monitor Agent cannot be used as a substitute for Defender for Endpoint.

  • If you are, however, still using MMA for other purposes (such as Log Analytics), MMA has been retired. See We're retiring the Log Analytics agent in Azure Monitor on 31 August 2024. Depending on your particular scenario, now might be a good time to upgrade to Azure Monitoring Agent, the successor of MMA.
