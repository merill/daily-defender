Defender for Servers provides threat detection and advanced defenses for your machines in Azure, AWS, and GCP. For more information, see Defender for Servers.

!Note

AWS and GCP machines require Azure Arc for onboarding. Some features, such as file integrity monitoring, depend on the Azure Monitor Agent (AMA) deployed through Arc.

Defender for DevOps

Defender for DevOps connects to your continuous integration and continuous delivery (CI/CD) platforms and provides security insights for your development pipelines. For more information, see Defender for DevOps.

  • Azure DevOps: GA.
  • GitHub: GA.
  • GitLab: GA.

Defender for APIs
