Defender Experts Hunting Ask Experts

4 September 2026Doc update+10 / −2 lines

In brief

The documentation now includes screenshots showing the Ask Defender Experts option on the Defender Experts overview page and in the message center. The page metadata and authoring identifier were also updated.

What Defender admins need to know

Administrators can use the new visuals to more easily find the Ask Defender Experts option in the Microsoft Defender portal.
