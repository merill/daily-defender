Connect Mend.io to Defender for Cloud (Preview)

4 September 2026Doc update+6 / −4 lines

In brief

The page date and authoring metadata were updated, the Mend.io account prerequisite and Azure portal link were reworded, and the section heading now reads “Connect Mend.io to Defender for Cloud.”

What Defender admins need to know

No administrator action is required.

  • GitHub organizations

  • GitLab groups

  • Have an account with the Mend.io website.

  • Obtain an activation key from Mend.io. For instructions, see Mend.io integration activation token Application Programming Interface (API).

  • Ensure repositories monitored by Mend.io are also connected to Defender for Cloud. Findings won't appear if those repositories aren't connected.

Connect Mend.io to Defender for Cloud

To connect your Mend.io account to Defender for Cloud:

  1. Sign in to the Azure portal at Azure portal.

  2. Navigate to Microsoft Defender for Cloud > Environment settings.
