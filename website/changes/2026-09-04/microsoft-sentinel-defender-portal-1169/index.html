Microsoft Sentinel Defender Portal

4 September 2026Doc update+1 / −1 lines

In brief

The AI-assisted SOC row now lists Native Security Copilot references for automated incident summaries, guided response actions, and script analysis.

What Defender admins need to know

Administrators can use the updated documentation links for these Security Copilot capabilities. No action is required.

Summaries are generated from the documentation change itself.
