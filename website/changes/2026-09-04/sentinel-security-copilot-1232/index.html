Sentinel Security Copilot

4 September 2026Doc update+4 / −3 lines

In brief

The Sentinel Security Copilot article now states that Sentinel data can be used in both the standalone Security Copilot portal and the embedded experience in the Microsoft Defender portal after Sentinel onboarding.

What Defender admins need to know

Administrators can use the updated guidance to identify both supported access paths. No action is required.
