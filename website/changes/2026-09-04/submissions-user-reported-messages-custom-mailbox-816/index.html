Submissions User Reported Messages Custom Mailbox

4 September 2026Doc update+7 / −3 lines

In brief

The documentation now states that reporting mailboxes cannot be distribution groups or external/on-premises mailboxes. It also notes that default investigation-result emails are localized to each recipient’s preferred language.

What Defender admins need to know

Review mailbox configuration and notification expectations; no administrator action is explicitly required.
