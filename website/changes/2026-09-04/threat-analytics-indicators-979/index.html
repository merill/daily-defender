Threat Analytics Indicators

4 September 2026Doc update+11 / −10 lines

In brief

The documentation now consistently refers to the Indicators tab, clarifies that access is available to verified customers, simplifies the verification steps, and updates related-content formatting.

What Defender admins need to know

Administrators can follow clearer instructions to request verification and access indicator lists.
