Review changes in file integrity monitoring

!Note

The older method of data collection uses the Log Analytics agent (also known as the Microsoft Monitoring agent (MMA)). Support for using the MMA ended in November 2024.

Use File Integrity Monitoring in Defender for Cloud to review tracked file and registry changes.

Prerequisites

Before you review file changes, make sure the following prerequisites are met:

  • Defender for Servers Plan 2 must be enabled.
  • File integrity monitoring with the Defender for Endpoint agent must be enabled. !Note

If you previously used File Integrity Monitoring over the Log Analytics agent (also known as the Microsoft Monitoring Agent, or MMA), you can return to that method by selecting Change to previous experience. The Change to previous experience option will be available until the FIM over MMA feature is deprecated. For information on the deprecation plan, see Prepare for retirement of the Log Analytics agent.
