Hunt for threats in app activities | Microsoft Defender for Cloud Apps

4 September 2026Feature update+10 / −6 lines

In brief

The documentation now states that queries return up to 1,000 results by default and can be edited to return up to 100,000 rows. Results exceeding 64 MB may be partial and trigger a notification; these limits do not apply to app governance.

What Defender admins need to know

When investigating suspicious app activity, administrators should check for partial-result notifications and account for possible delays in app governance data.

Hunt for threats in app activities
