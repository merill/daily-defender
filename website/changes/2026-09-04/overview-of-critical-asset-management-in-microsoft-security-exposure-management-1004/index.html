  • Microsoft Defender automatically detects and categorizes critical assets, streamlining identification and enabling immediate protection.
  • Your security team can prioritize security investigations, posture recommendations, and remediation steps to focus on critical assets and systems first.
!Tip

If you arrived here from an alert or incident investigation in Microsoft Defender XDR, critical asset information tells you whether the affected device, identity, or cloud resource is classified as business-critical. Assets marked as critical appear with a crown indicator in the Defender portal. To view or adjust classifications, go to Exposure management > Critical assets in the Microsoft Defender portal. To manage classifications, see Review and classify critical assets. If you manage cloud assets in Microsoft Defender for Cloud, see Critical assets protection in Microsoft Defender for Cloud.
