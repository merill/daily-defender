Suppress alerts from Microsoft Defender for Cloud

4 September 2026Doc update+3 / −3 lines

In brief

The documentation now states that deleting a suppression rule does not change alerts it previously dismissed and identifies DELETE as the method for removing the rule.

What Defender admins need to know

Administrators can better understand the effect of removing suppression rules; no configuration change is required.
