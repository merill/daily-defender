In brief

The Sentinel Power BI article now explains that scheduled refresh is configured on the report’s backing dataset, which is created when the report is published. It also specifies the required Log Analytics read-access credentials and adds detail about query results and published reports.

What Defender admins need to know

Administrators configuring scheduled refresh should use the report dataset and ensure suitable Log Analytics access credentials are available.
