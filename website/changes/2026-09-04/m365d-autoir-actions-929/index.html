4 September 2026Doc update+7 / −4 lines

In brief

The page now links to the Microsoft Defender Action center and clarifies that **Apply to X more instances of the selected quarantined file** is used before selecting **Undo**. The documentation date was also updated.

What Defender admins need to know

Administrators can follow the multi-device undo procedure more clearly; no action is required.

To undo multiple remediation actions at once:

  1. Go to the Action center (Microsoft Defender Action center) and sign in.

  2. On the History tab, select the actions that you want to undo. Make sure to select items that have the same Action type. A flyout pane opens.

Remove a file from quarantine across multiple devices

To remove a quarantined file from multiple devices at once, perform the following steps:

  1. Go to the Action center (https://security.microsoft.com/action-center) and sign in.

  2. On the History tab, select a file that has a Quarantine file Action type.

  3. In the pane on the right side of the screen, select Apply to X more instances of thisthe selected quarantined file, and then select Undo.
