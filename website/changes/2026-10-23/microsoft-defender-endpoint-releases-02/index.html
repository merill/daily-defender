Microsoft Defender Endpoint Releases

23 October 2026New feature+18 / −2 lines

In brief

The October 2026 Android release notes document Silent running mode for Shared Device Management. Administrators can set SilentRunMode to 1 to enable it or 0 (the default) to disable it.

What Defender admins need to know

Administrators managing shared Android devices can configure this setting; no required action is stated.
