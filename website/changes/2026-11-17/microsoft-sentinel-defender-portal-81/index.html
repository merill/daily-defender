Microsoft Sentinel Defender Portal

17 November 2026Doc update+27 / −22 lines

In brief

The documentation now reflects revised Microsoft Defender portal locations for Sentinel capabilities, including hunting, workbooks, threat intelligence, content management, connectors, analytics, watchlists, automation, and settings.

What Defender admins need to know

Use the updated paths when navigating the Defender portal; no configuration change is specified.
