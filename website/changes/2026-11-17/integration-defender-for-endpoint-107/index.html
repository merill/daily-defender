Integration Defender For Endpoint

17 November 2026Feature updateAction required+4 / −1 lines

In brief

The documentation now states that the Microsoft Defender for Endpoint agent is required for Plan 1 capabilities on Linux and other non-Windows servers, and is needed to access the full Plan 1 capability set.

What Defender admins need to know

Verify that the Defender for Endpoint agent is deployed on applicable servers to access the documented Plan 1 capabilities.
