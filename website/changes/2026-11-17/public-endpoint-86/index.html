17 November 2026Doc update+4 / −6 lines

In brief

The documentation now directs Defender portal users to Investigation & response > Notebooks. The Azure portal path is unchanged.

What Defender admins need to know

Use the updated Defender portal navigation when accessing Sentinel notebooks; no configuration change is required.

Public endpoint

Use the following steps to create an Azure Machine Learning workspace with a public endpoint from Microsoft Sentinel.

  1. For Microsoft Sentinel in the Azure portal, under Threat management, select Notebooks. For Microsoft Sentinel in the Defender portal, select Microsoft Sentinel > Threat managementInvestigation & response > Notebooks.

  2. Select Configure Azure Machine Learning > Create a new AML workspace.

  3. Enter the following details, and then select Next.

  4. Create a virtual machine (VM) jump box within a virtual network. Since the virtual network restricts access from the public internet, the jump box is used as a way to connect to resources behind the virtual network.

  5. Access the jump box, and then go to your Microsoft Sentinel workspace. We recommend using Azure Bastion to access the VM.

  6. For Microsoft Sentinel in the Azure portal, under Threat management, select Notebooks. For Microsoft Sentinel in the Defender portal, select Microsoft Sentinel > Threat managementInvestigation & response > Notebooks.

  7. Select Configure Azure Machine Learning > Create a new AML workspace.

  8. Enter the following details, and then select Next.

To launch your Microsoft Sentinel notebook in your Azure Machine Learning workspace, complete the following steps.

  1. For Microsoft Sentinel in the Azure portal, under Threat management, select Notebooks. For Microsoft Sentinel in the Defender portal, select Microsoft Sentinel > Threat managementInvestigation & response > Notebooks.
  2. Select the Templates tab to see the notebooks that Microsoft Sentinel provides.
  3. Select a notebook to view its description, required data types, and data sources.
  4. When you find the notebook you want to use, select Create from template and Save to clone it into your own workspace. Only Azure Machine Learning workspaces in the same subscription can be selected.
