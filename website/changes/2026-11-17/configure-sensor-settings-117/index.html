Configure Sensor Settings

17 November 2026Doc update+7 / −7 lines

In brief

The page now directs administrators to Settings > Identities > On-premises > Sensor Management. It also updates the steps to use the v2.x sensor row actions menu and Settings option, and refreshes related labels and screenshot text.

What Defender admins need to know

Use the revised navigation and controls when managing Defender for Identity sensors. No mandatory administrator action is stated.
