Advanced hunting overview in Microsoft Defender - Microsoft Defender XDR | Microsoft Learn

Advanced hunting is a query-based threat hunting tool that you use to explore up to 30 days of raw Defender data.data, or up to 90 days of supported data with an eligible Integrated Security Operations Center (ISOC) license. When you onboard a Microsoft Sentinel workspace, you can also query analytics-tier data according to the retention configured for the workspace. You can proactively inspect events in your network to locate threat indicators and entities. The flexible access to data enables unconstrained hunting for both known and potential threats.

Advanced hunting supports two modes: guided and advanced. Use guided mode if you're not yet familiar with Kusto Query Language (KQL) or if you prefer the convenience of a query builder. Use advanced mode if you're comfortable using KQL to create queries from scratch.

Extend data retention

To retainAdvanced hunting supports up to 30 days of native Defender data retention by default. With ISOC, customers who have an eligible Microsoft Defender Suite, Microsoft 365 E5, or Microsoft 365 E7 license receive 90 days of included retention for supported Microsoft Defender data, Azure Activity data, and Office 365 Activity data.

The 90-day retention benefit applies to supported workloads. For the list of included tables, see Tables included with 90-day retention.

When 90-day retention is enabled for your tenant and the required data is available, you can run advanced hunting tables forqueries that look back more than 30 days.

For queries that exceed 30 days, onboard athe query details pane shows:

  • Data sources: Kusto instead of Log Analytics.
  • Age of processed data: The actual duration queried.
