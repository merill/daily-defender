Data Federation Setup

17 November 2026Doc update+12 / −11 lines

In brief

The instructions now use the Defender portal’s Setup & configuration > Data management > Data & connectors path, with connector discovery on the Connectors tab. They also update the Azure Data Lake Storage connector name to Azure Data Lake Storage Gen2 and clarify how to view and manage instances.

What Defender admins need to know

Administrators following the setup guide should use the updated navigation and Add new instance option when configuring federated connectors.

View and manage federated data connectors in the Defender portal

FederatedManage federated connectors are managed on the Connectors tab of Data & connectors page in Microsoft Sentinel on the Defender portal.

  1. Navigate toIn the Defender portal, select Microsoft Sentinel > ConfigurationSetup & configuration > Data management > Data & connectors., and then select the Connectors tab.

  2. Under Data federation, select Catalog to view the available federated connectors.

    The catalog page displays:

    • Number of configured instances for each connector
    • Publisher and support information

  3. Select a connector in the catalog to view its description and prerequisites. For Azure Data Lake Storage Gen2, select Add new instance to create an instance.

  4. Under Data federation, select My connectors page to view all configured connector instances. The page lists your tenant's data federation connector instances along with their display name, version, status, and support provider.

  5. Select each instance to view details, edit configurations, or delete the instance.

Create a connector instance

  1. If you're creating a new storage account, ensure the Hierarchical namespaces setting is enabled.

  2. Assign the Storage Blob Data Reader role to the service principal you created earlier. For more information on granting access through the Azure portal, see Assign Azure roles using the Azure portal - Azure RBAC.

  3. On the Data federation > Catalog page, select Azure Data Lake Storage Gen2.

  4. Select Connect a connectorAdd new instance.

After creating a connector instance check that the tables you federated are available in Microsoft Sentinel.

  1. Navigate toIn the Defender portal, select Microsoft SentinelSetup & configuration > ConfigurationData management > Data & connectors, and then select the Tables. tab.
  2. Filter by Type Federated to see all federated tables.
  3. Search by your connector instance name.
  4. Tables from your connector instance are listed with their name followed by _instance name. For example if your data connector instance name was GlobalHRData and your table was called hrlogs, your table name is shown as hrlogs_GlobalHRData.
