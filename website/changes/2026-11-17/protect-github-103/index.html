Protect Github

17 November 2026New feature+72 / −23 lines

In brief

The documentation adds Enterprise-level onboarding alongside Organization-level connections. Enterprise connections cover all organizations through one connector and automatically disable existing organization-level connectors in that enterprise.

What Defender admins need to know

Choose the connection level and use the corresponding OAuth setup, permissions, and enterprise slug. Review existing connectors before selecting Enterprise level.

The main threats to GitHub Enterprise Cloud environments include:

  • Device code phishing and related OAuth token abuse
  • Compromised accounts and insider threats
  • Data leakage
  • Insufficient security awareness

Connect GitHub Enterprise Cloud to Microsoft Defender for Cloud Apps

Use the following steps to connect Microsoft Defender for Cloud Apps to your existing GitHub Enterprise Cloud organization using the App Connector APIs. This connection gives you visibility into and control over your organization's GitHub Enterprise Cloud use. You can connect at either the Organization level or the Enterprise level. For more information about how Defender for Cloud Apps protects GitHub Enterprise Cloud, see Protect GitHub Enterprise.

Use this app connector to access SaaS Security Posture Management (SSPM) features, via security controls reflected in Microsoft Secure Score. Learn more.

Choose a connection level

Use the following guidance to choose how to connect GitHub Enterprise Cloud.

Connection levelBest forCoverageAdministrative modelRecommendation
Enterprise levelEnterprises with one or more organizationsAll organizations in the enterpriseSingle connectorRecommended and it also provides advanced detection and disruption capabilities
Organization levelSingle organization onboardingOne organization is coveredOne connector per organizationSupported

Important

If you connect GitHub at the Enterprise level, existing Organization-level connectors for organizations in that enterprise are automatically disabled to prevent duplicate event ingestion.

Prerequisites

Before you connect GitHub Enterprise Cloud to Defender for Cloud Apps, make sure the following prerequisites are met:

  • Your organization must have a GitHub Enterprise Cloud license.
  • TheDecide which connection level you'll use: Organization or Enterprise.
  • For Organization-level connection, the GitHub account used for connecting to Defender for Cloud Apps must have Owner permissions for your organization.
  • For SSPM capabilities, the provided account must be the owner of the enterprise account.
  • For Enterprise-level connection, the GitHub account used for connecting to Defender for Cloud Apps must have Enterprise owner permissions on the enterprise.
  • To verify owners of your organization, browse to your organization's page, select People, and then filter by Owner.
  • To verify owners of your enterprise, browse to your enterprise page, select People, and then filter by Owner.
