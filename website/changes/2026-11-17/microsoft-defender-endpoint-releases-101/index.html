Microsoft Defender Endpoint Releases

17 November 2026Feature updateAction required+5 / −0 lines

In brief

Starting with version 101.26091.0003, Defender for Endpoint on Linux requires `iptables`; RPM packages also require `libacl`. The installer script and Defender deployment tool install these dependencies automatically.

What Defender admins need to know

Ensure these dependencies are available when installing packages directly; automated installation tools handle them automatically.

Linux | November 12, 2026 | Update for version 101.26091.0003: new package dependencies

Starting with version 101.26091.0003, Defender for Endpoint on Linux packages require iptables, which device isolation uses. RPM packages also require libacl. The installer script and the Defender deployment tool install these dependencies automatically. If you install directly with rpm or dpkg, install these dependencies first; otherwise, the installation or upgrade fails. For more information, see Prerequisites for Microsoft Defender for Endpoint on Linux.
