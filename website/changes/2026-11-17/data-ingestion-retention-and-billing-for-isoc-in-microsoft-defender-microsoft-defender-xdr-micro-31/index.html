Data ingestion, retention, and billing for ISOC in Microsoft Defender - Microsoft Defender XDR | Microsoft Learn

17 November 2026Feature update+100 / −21 lines

In brief

Documentation changes the included retention guidance from 30 to up to 90 days for supported Microsoft Defender data starting November 15, 2026. It also documents retention by supported table, extension up to 180 days for additional charges, and separate billing for additional Microsoft and non-Microsoft data.

What Defender admins need to know

Review supported data sources, retention requirements, and potential charges. Extended retention applies only to new data and does not backfill previously collected data.

Integrated Security Operations Center (ISOC) in Microsoft Defender supports Microsoft security data and additional Microsoft and non-Microsoft security data.

Note

ISOC is in preview. Capabilities and availability might change during the preview period.

How data is handled

Native Microsoft Defender data is available directly in the Microsoft Defender experience and doesn't need to be separately ingested into an ISOC workspace.

Other supported Microsoft and non-Microsoft data can be connected through an ISOC workspace by using data connectors.data connectors.

Microsoft security data

  • Microsoft Defender for Identity
  • Microsoft Defender for Cloud Apps
  • Microsoft Defender for Cloud
  • Microsoft Entra Identity Protection logs
  • Azure Activity and audit logs through a connector
  • Office 365 Activity and audit logs through a connector

Eligible customers with Microsoft Defender Suite, Microsoft 365 E5, or Microsoft 365 E7 can use supported Microsoft Defender security data as part of the ISOC experience.

Note

During this phase of the preview, eligible customers receive 30 days of included retention for Defender data.

For Microsoft 365 E5 plan details and pricing, see Microsoft 365 E5 for Enterprise.

To compare the security capabilities included with Microsoft 365 enterprise plans, see Microsoft 365 Security Enterprise Plans.

90-day retention

Starting November 15, 2026, eligible customers receive up to 90 days of included retention for supported Microsoft Defender data.

The retention benefit applies at the workload level. As additional supported tables become available for an included workload, they'll also be included in the retention benefit.

Extend Microsoft Defender data retention

You can extend retention for supported Microsoft Defender data up to a maximum of 180 days.

Extended retention applies to new data after you enable it. Data that was collected before you enabled extended retention isn't backfilled.

Additional charges apply when you extend retention beyond the retention included with ISOC.

Choose a retention option

Use the retention option that matches how you plan to use the data:

  • Use interactive retention for data that analysts need for investigations, hunting, and ongoing security operations.
  • Use data lake retention for data that you keep primarily for longer-term analysis, audit, or compliance scenarios.
