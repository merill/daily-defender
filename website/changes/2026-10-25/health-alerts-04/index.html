Health Alerts

25 October 2026Doc update+2 / −6 lines

In brief

The health-alert documentation now identifies Windows Server 2016 as approaching extended end of support and links to Legacy operating systems guidance. Windows Server 2012 and 2012 R2 remain identified as unsupported.

What Defender admins need to know

Administrators can use the linked guidance to assess sensors running on operating systems nearing or past support.
