Microsoft Defender for Cloud Apps
Cloud and workloads

Manage Admins

4 October 2026Retirement+5 / −1 lines

In brief

App/instance admin and User group admin role assignments can no longer be used in new configurations. Existing configurations remain supported.

What Defender admins need to know

No action is required for existing assignments. Organizations needing these capabilities should contact Microsoft Support.

Note

The App/instance admin and User group admin role assignments are no longer available for new configurations as part of platform consolidation efforts. Existing configurations aren't affected and continue to be supported. If your organization requires these capabilities, contact Microsoft Support.

Important

Microsoft recommends that you use roles with the fewest permissions. Using least-privilege roles helps improve security for your organization. Global Administrator is a highly privileged role that should be limited to emergency scenarios when you can't use an existing role.
