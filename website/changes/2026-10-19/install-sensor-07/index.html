Install Sensor

19 October 2026Doc update+2 / −2 lines

In brief

The guide now specifies that eligible Windows Server 2019 or later domain controllers should follow the v3.x deployment guidance, not the v2.x installer procedures. It also links to the v3.x onboarding package for deployments without Defender for Endpoint.

What Defender admins need to know

Administrators can use the clarified guidance to select the appropriate v3.x deployment and onboarding path.
