Sensor Settings

19 October 2026Doc update+3 / −3 lines

In brief

The section now refers to removing the legacy Unified Sensor RPC Audit tag and clarifies that removing it does not disable automatic RPC auditing on v3.x sensors.

What Defender admins need to know

Administrators can remove the tag by deleting the asset rule or changing its conditions; no action is required unless they manage these legacy rules.

## Remove legacy RPC auditing from a devicetags

From sensor version 3.0.8, RPC auditing is enabled automatically when the sensor is upgraded and no longer requires a tag.

If you configured RPC auditing for an earlier v3.x sensor using the **Unified Sensor RPC Audit** tag, you can remove itthe legacy tag by deleting the asset rule or modifying the rule conditions so the device no longer matches. Removing the tag doesn't disable automatic RPC auditing on v3.x sensors that no longer require it.

To manage asset rules, in the [Microsoft Defender portal](https://security.microsoft.com), go to **System &gt; Settings &gt; Microsoft Defender XDR &gt; Asset Rule Management**.
