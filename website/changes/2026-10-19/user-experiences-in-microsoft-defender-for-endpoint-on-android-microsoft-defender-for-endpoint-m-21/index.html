In brief

The page now describes the refreshed Android interface, including dashboards, feature tiles, alert cards, and the Device Protection feature card. It also clarifies the separate feedback and log-submission flows and updates screenshot descriptions, wording, and formatting.

What Defender admins need to know

Administrators should be aware that users have distinct options for submitting feedback with logs versus sending logs without written feedback; no administrator action is stated.
