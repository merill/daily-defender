Migrate To Sensor V3

19 October 2026Doc updateAction required+4 / −2 lines

In brief

The guide now says to select “Automatically use the sensor's local system account” before migrating because migration does not change this setting automatically. It also instructs admins to verify that the setting remains selected instead of using gMSA for action accounts.

What Defender admins need to know

Admins migrating to sensor v3 must verify this setting beforehand; leaving gMSA selected can affect response actions.
