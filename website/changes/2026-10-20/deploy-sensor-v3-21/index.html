Deploy Sensor V3

20 October 2026Feature update+2 / −2 lines

In brief

The documentation now states that eligible servers can use sensor v3.x onboarding without Defender for Endpoint deployment, replacing the previous domain-controller-specific wording.

What Defender admins need to know

Administrators deploying sensor v3 on eligible servers can use this documented onboarding option; no action is required.
