Azure Portal Vs Defender Portal Comparison

20 October 2026Doc update+7 / −2 lines

In brief

The comparison now documents Defender portal preview support for environment onboarding, plan management, and cloud security cost reporting. It also clarifies that data export remains available in the Azure portal.

What Defender admins need to know

Administrators can use the updated comparison to identify which portal supports each capability; no action is specified.
