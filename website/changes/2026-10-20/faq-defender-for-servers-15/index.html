New Defender server security experience

Do servers already running Defender for Endpoint need any changes?

No. They continue running as usual; no onboarding, reinstallation, or migration is required. See Existing deployments.

Where do I start with new servers?

Use Onboard servers to choose a method and prepare deployment. For an on-premises connection to Defender for Servers, see Connection options.

Can I limit Direct onboarding to selected servers?

No. It applies to existing and future eligible servers in the same tenant, rather than a selected pilot group. Review who is affected before enabling it.

Which offboarding method should I use?

For an Azure environment, turning off Defender for Servers starts the automatic flow for eligible servers. Use manual endpoint offboarding for individual endpoints. Neither path should be treated as proof that installed software was removed. See Offboarding options and outcome checks.

Why does an offboarded server still appear?

Historical data can remain visible under the retention policy. A retained record doesn't prove that protection or reporting is active. See Historical records.
