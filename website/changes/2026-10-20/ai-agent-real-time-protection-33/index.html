Ai Agent Real Time Protection

20 October 2026Feature update+1 / −1 lines

In brief

The documentation now states that block events from Microsoft Prompt Shields for Foundry, Copilot Studio, and Copilot Agent Builder are recorded as behaviors.

What Defender admins need to know

Administrators can expect Prompt Shields block events from Copilot Studio agents to appear as recorded behaviors; no configuration change is required.
