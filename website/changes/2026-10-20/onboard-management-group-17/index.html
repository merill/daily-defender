In brief

The article now clarifies that it covers using Azure Policy to enable Defender for Cloud across subscriptions in a management group, and links to separate guidance for connecting Azure environments in the Defender portal.

What Defender admins need to know

Administrators can more easily find the appropriate instructions for policy-based onboarding versus portal connection.

You can use Azure Policy to enable Microsoft Defender for Cloud on all the Azure subscriptions in the same management group. This approach is more convenient than accessing them individually from the portal, and works even if the subscriptions belong to different owners.

Note

This article describes how to use Azure Policy to enable Defender for Cloud across subscriptions in a management group. To connect an Azure management group to the Microsoft Defender portal and manage plan coverage there, see Connect Azure environments in the Defender portal and Manage Defender for Cloud plans in the Defender portal.

Prerequisites

Before you onboard the management group, register the required resource provider.
