Uninstall Sensor

20 October 2026Doc updateAction required+6 / −6 lines

In brief

The guidance now applies to servers, specifically v3.x sensors deployed without Defender for Endpoint. Administrators must run the offboarding package on the server before deleting its portal entry; deleting the entry alone may leave the sensor active, sending data, and able to reactivate.

What Defender admins need to know

Administrators offboarding affected v3.x sensors should use the package before removing the sensor from the portal.

Remove the Microsoft Defender for Identity sensor when you need to decommission a server, clean up orphaned or duplicate sensor entries, or stop Defender for Identity monitoring on a specific server. For sensors onboarded without Microsoft Defender for Endpoint deployment, follow the dedicated offboarding procedure before removing the sensor entry.

Offboard a domain controllerserver without Defender for Endpoint deployment

For a domain controllerserver onboarded without Defender for Endpoint deployment, run the offboarding package on the domain controllerserver before removing the v3.x sensor from the portal. Removing the portal entry alone doesn't uninstall the v3.x sensor component. The v3.x sensor can continue sending data and reactivate.

  1. On the Sensor management tab of the On-premises page in the Microsoft Defender portal at https://security.microsoft.com/securitysettings/identities, select the v3.x sensor, and then select Delete.

  2. In the removal dialog, select Download offboarding package.

  3. Copy the downloaded offboarding package to the domain controller.server.

  4. Open PowerShell as an administrator, and change to the folder that contains the offboarding package.

  5. Run the deployment tool with the full path to the .offboarding file:

Important

For a v3.x sensor onboarded without Defender for Endpoint deployment, complete Offboard a domain controllerserver without Defender for Endpoint deployment before deleting the sensor entry.

To delete a v3.x sensor from the Microsoft Defender portal, follow these steps:

  1. On the Sensor management tab of the On-premises page in the Microsoft Defender portal at https://security.microsoft.com/securitysettings/identities, select the domain controllerserver where you want to deactivate Defender for Identity capabilities.

  2. Select Delete, and confirm your selection.
