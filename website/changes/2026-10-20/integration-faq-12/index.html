20 October 2026Feature update+48 / −10 lines

In brief

The documentation now states that cloud security data supports Azure, AWS, and GCP, while onboarding and plan management currently support Azure commercial environments only. After migration, plan settings become view-only in the Azure portal, resource-level configurations are not preserved, and billing uses Defender Workload Units.

What Defender admins need to know

Review environment eligibility, configuration preservation, and billing implications before moving an Azure environment to Defender-based plan management.
