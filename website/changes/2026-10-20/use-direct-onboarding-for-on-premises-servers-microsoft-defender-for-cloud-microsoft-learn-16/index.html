Use Direct onboarding for on-premises servers - Microsoft Defender for Cloud | Microsoft Learn

20 October 2026Feature updateAction required+49 / −55 lines

In brief

The procedure now states that direct onboarding affects all eligible existing and future non-Azure servers in the same Microsoft Entra tenant. Individual-server or pilot-group selection isn't supported, and prerequisites include healthy Defender for Endpoint telemetry, a matching tenant, and specific roles.

What Defender admins need to know

Review the full affected population, including Azure Arc-connected servers, and verify prerequisites before enabling the setting.
