Activate Sensor

20 October 2026Feature update+9 / −9 lines

In brief

The documentation now describes Defender for Identity sensor v3.x onboarding without Defender for Endpoint for eligible servers, including domain controllers, AD FS, AD CS, and Microsoft Entra Connect.

What Defender admins need to know

Administrators can apply the updated server-focused onboarding and offboarding steps to these supported server types.

Use onboarding without Defender for Endpoint deployment to activate the Defender for Identity sensor v3.x without first onboarding theon eligible servers. Supported servers include domain controller to Defender for Endpoint:controllers, AD FS, AD CS, and Microsoft Entra Connect.

Note

This onboarding method supports new Defender for Identity sensor v3.x deployments on eligible domain controllersservers that don't have sensor v2.x installed. The standalone onboarding package activates sensor v3.x on the Windows Sense platform in restricted identity-only mode. It doesn't deploy or license the full Defender for Endpoint experience. The server still requires connectivity to Defender for Endpoint cloud services because the underlying Sense component uses that infrastructure.

  1. Configure your network environment to ensure connectivity with Defender for Endpoint by using streamlined URLs.

  2. On the Sensor management tab of the On-premises page in the Microsoft Defender portal, select Download onboarding package. Important

    The access key is used only during sensor installation. Regenerating the key invalidates the existing key, and installations that use the previous key fail.

  3. Copy the downloaded package to the domain controller.server.

  4. Extract the package, making sure the resources subfolder is preserved.
