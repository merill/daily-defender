Migrate Microsoft Sentinel alert-trigger playbooks to automation rules | Microsoft Learn

9 November 2026RetirementAction required+17 / −21 lines

In brief

The article now states that alert-trigger playbooks and their Microsoft Sentinel Alert triggers remain supported, but direct invocation from analytics rules is deprecated. It updates the guidance to configure automation rules for alerts from one or multiple analytics rules.

What Defender admins need to know

Administrators relying on direct invocation should configure automation rules to keep these playbooks running automatically when alerts are created.
