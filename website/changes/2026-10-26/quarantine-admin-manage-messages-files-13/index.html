In brief

The page updates its date and link ordering, renames an existing quarantine permission entry to “View and release emails and messages from quarantine,” and adds guidance for submitting quarantined messages to Microsoft, including read permissions for Security data basics and Email & collaboration metadata.

What Defender admins need to know

Review the updated permission names and role paths when managing administrator access to quarantine actions.
