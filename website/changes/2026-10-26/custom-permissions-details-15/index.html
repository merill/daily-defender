26 October 2026Doc update+5 / −5 lines

In brief

The permission details now state that Email & collaboration metadata Read access includes submitting email messages by Network message ID on the Submissions page. Documentation metadata and ontology links were also updated.

What Defender admins need to know

Review this expanded permission description when assessing custom role access to email and collaboration data.
