Geographical Availability Data Residency

26 October 2026Feature update+3 / −9 lines

In brief

The page now states that Sentinel will process and store processed and configuration data in the onboarding destination regions or applicable existing Defender XDR regions. It also adds cases to the processed-data examples and removes the 21Vianet retirement notice.

What Defender admins need to know

Use the updated data-residency description when assessing where Sentinel data is handled.

This article can help you meet compliance requirements by describing where Microsoft Sentinel data is stored.

Important

Microsoft Sentinel was retired in Azure operated by 21Vianet on August 18, 2026, as described in the announcement posted by 21Vianet. Microsoft Sentinel is no longer available in this region.

We recommend that customers work with their account representatives for Microsoft Azure operated by 21Vianet to assess the impact of this retirement on their own operations.

Collected data

Microsoft Sentinel collects the following types of data:

  • Raw data, such as event data collected from connected Microsoft services and partner systems. Data from multiple clouds and sources are streamed to the customer’s Azure Log Analytics workspace associated with Microsoft Sentinel, under the customer’s tenant’s subscription. This approach gives the customer the ability to choose region and retention and deletion policies.
  • Processed data, such as incidents, alerts, behaviors, cases, and so on.
  • Configuration data, such as connector settings, rules, and so on.

Data storage location

  • For Log Analytics workspaces located in Israel, Microsoft Sentinel processes customer data in Israel.
  • For workspaces located in any other location, Microsoft Sentinel processes customer data in a US region.

When you onboard Microsoft Sentinel from the Defender portal, the service mightwill process and store "Processed data" and "Configuration data" in the destination regions specified during onboarding, or in the existing Microsoft Defender XDR regions if applicable. The raw data storage location, however, remains unchanged. For more information, see Data security and retention in Microsoft Defender XDR.
