Defender Sensor Change Log

26 October 2026Feature update+30 / −4 lines

In brief

The changelog adds October 2026 GA entries for sensor versions 0.11.9, 0.10.12, 0.9.70, and 0.8.63. Their images remove trust in affected certificate authorities.

What Defender admins need to know

Review these releases when planning sensor updates. No administrator action is specified.
