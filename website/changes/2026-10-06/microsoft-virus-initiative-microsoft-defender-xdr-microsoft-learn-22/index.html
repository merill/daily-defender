Microsoft Virus Initiative - Microsoft Defender XDR | Microsoft Learn

6 October 2026Doc update+2 / −2 lines

In brief

The virus initiative criteria page updates its VB100 entry from Grade C or higher to Grade B or higher for a 95% detection rate. Its platform identifier was also updated.

What Defender admins need to know

Administrators reviewing VB100 criteria should use the updated Grade B-or-higher requirement. No action is required.
