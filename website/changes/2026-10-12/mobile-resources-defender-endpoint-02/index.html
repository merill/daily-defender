Mobile Resources Defender Endpoint

12 October 2026Doc update+7 / −1 lines

In brief

The documentation now lists onboarding, security reporting, and iOS TVM as Mobile TVM service uses. It also warns that restrictive Conditional Access policies can disrupt these flows and recommends excluding the service from those policies.

What Defender admins need to know

Review Conditional Access policies affecting the Mobile TVM service to help prevent communication disruptions.
