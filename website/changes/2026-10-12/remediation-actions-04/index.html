Microsoft Defender for Identity
Identity protection

Remediation Actions

12 October 2026Feature update+4 / −4 lines

In brief

The Defender for Identity remediation-actions table now lists Security Operator among the roles for the Revoke session action.

What Defender admins need to know

Administrators can include this role when reviewing or assigning permissions for session revocation.

Summaries are generated from the documentation change itself.
