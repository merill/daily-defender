Azure Portal Vs Defender Portal Comparison

10 November 2026Feature update+6 / −4 lines

In brief

The documentation now lists Microsoft Cloud Security Benchmark, security policies, exemptions, and regulatory compliance assessments as available in preview for Azure environments in the Defender portal.

What Defender admins need to know

Administrators can use the updated comparison to identify Azure security tasks available in the Defender portal. No required action or deadline is stated.
