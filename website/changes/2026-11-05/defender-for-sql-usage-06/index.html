Defender For Sql Usage

5 November 2026Feature update+59 / −6 lines

In brief

The guidance now supports Azure Arc SQL Server instances with Arc proxy enabled when using Defender for SQL extension version 2.0.3585.403 or later. It documents proxy, direct, and Azure Monitor Agent communication fallback, required outbound access, and a discovery script.

What Defender admins need to know

Administrators can verify network prerequisites, extension versions, and affected Windows Arc machines before enabling or managing Defender for SQL through an Arc proxy.
