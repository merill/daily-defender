Normalization Manage Parsers

8 October 2026Doc update+11 / −10 lines

In brief

The parser-management documentation updates custom unifying-function examples to pass `disabled=disabled` where supported, including AgentEvent and DNS parser examples, and adds or updates parser entries.

What Defender admins need to know

Administrators creating custom normalization parsers can use the updated parameter lists to verify compatibility between unifying and source-specific parsers.

Summaries are generated from the documentation change itself.
