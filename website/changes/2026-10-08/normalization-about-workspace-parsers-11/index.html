Normalization About Workspace Parsers

8 October 2026Doc update+22 / −13 lines

In brief

The documentation adds AgentEvent and AssetEntity entries, updates the ProcessEvent listing, and revises parser examples to show explicit parameter-to-column mappings. Several examples also include fields such as `pack` and `disabled`.

What Defender admins need to know

Administrators using these tables to build or review parser-based queries will find updated schema names and parameter mappings.
