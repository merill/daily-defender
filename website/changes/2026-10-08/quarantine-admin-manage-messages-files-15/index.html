Quarantine Admin Manage Messages Files

8 October 2026Doc update+4 / −10 lines

In brief

The instructions now state that the Source tab displays the message body as HTML with links disabled. The separate Plain text tab description was removed, and the metadata date was updated.

What Defender admins need to know

Administrators reviewing quarantined messages should use the Source tab guidance when inspecting message content.
