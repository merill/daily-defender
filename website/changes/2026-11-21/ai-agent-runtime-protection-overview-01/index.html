Ai Agent Runtime Protection Overview

21 November 2026Feature update+6 / −4 lines

In brief

The documentation now states that enabling prompt evidence collection sends prompts and tool calls, including arguments, to the cloud in their original form. Captured content may appear in security alerts and is retained under the Microsoft Defender XDR data retention policy.

What Defender admins need to know

Review privacy and data-handling requirements before enabling collection, since sensitive content and secrets are not redacted.

Prompt evidence collection

Prompt evidence collection is a device setting for AI agent runtime protection.

When prompt evidence collection is enabledenabled, Defender sends prompt data and runtime protectiontool calls, including their arguments, to the cloud to help detect threats and investigate suspicious agent activity. This content is enabledsent in Audit or Block mode, Defender exposes prompt snippets exchanged betweenits original form, without redaction. Captured content can also appear in security alerts. Disabling collection stops this content from being sent to the user and the agent to support deeper analysis of agent-related alerts. These snippets include only the portions of user prompts or agent responses identified as suspicious and relevant to security classification.cloud, which limits detections that rely on analyzing it.

Note

Important

Sensitive data and secrets aren't redacted from prompt snippets shown in alerts. These snippets can contain users' conversations, sensitive data, and secrets. Review your organization's privacy and data-handling requirements before you enable collection. Evidence included in security alerts is retained according to the Microsoft Defender XDR data retention policy.

Disabling device-level collection doesn't disable runtime protection. Content associated with activity that Defender blocks can still appear in the associated security alert.

Configure device collection through PowerShell or the policy template. For prerequisites, commands, and deployment steps, see Configure prompt evidence collection.
