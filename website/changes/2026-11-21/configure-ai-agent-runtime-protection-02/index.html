Configure Ai Agent Runtime Protection

21 November 2026Doc update+2 / −2 lines

In brief

The documentation now states that enabling prompt evidence collection sends prompt data and tool calls, including arguments, to the cloud in their original, unredacted form.

What Defender admins need to know

Administrators should account for this data handling when enabling prompt evidence collection. No required action is stated.
