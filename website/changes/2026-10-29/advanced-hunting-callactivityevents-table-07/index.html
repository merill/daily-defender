In brief

The table now documents fields for call type, activity details and status, initiators, recipients, tenants, account types, and client platforms. The page also removes a note about planned event streaming API, Microsoft Sentinel integration, and additional attributes.

What Defender admins need to know

No administrator action is stated. Hunting queries can use the newly documented columns for more detailed call analysis.
