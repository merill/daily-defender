29 October 2026New feature+4 / −3 lines

In brief

The documentation now lists the CloudKeyVaultEvents table, marked Preview, for operations performed against Azure Key Vault resources.

What Defender admins need to know

Administrators can review this table when investigating Azure Key Vault activity. No action is required.
