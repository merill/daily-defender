When you're setting set up or maintainingmaintain Defender for Business, an important task is reviewing and configuring device policies:

  • Default policies:

    • Attack surface reduction features

  • Settings for advanced features:

    • Turn on (or off) advanced features;
    • Specifying which time zone to use in the Microsoft Defender portal; and
    • Whether to receive preview features as they become available.

Choose where to manage security policies and devices

Before you create or edit security policies, you need to decide which portal to use:

  • Microsoft Defender portal at Microsoft Defender portal.
  • Microsoft Intune admin center at Microsoft Intune admin center.

The following table explains both options.

Option Description
Defender portal A one-stop shop for managing company devices, security policies, and security settings in Defender for Business. With a simplified configuration process, you can use the Defender portal to:
- Onboard devices.
- Access your security policies and settings.
- Use the Microsoft Defender Vulnerability Management dashboard.
- View and manage incidents

.
Intune admin center Although Defender for Business doesn't include Microsoft Intune, you can use the Intune admin center to:
- Manage your company devices and apps, including how they access your company data.
- Onboard devices and access your security policies and settings in Intune.
- Set up and configure attack surface reduction rules.

If your company has Intune, you can continue using Intune to manage your devices and security policies. To learn more, see Manage device security with endpoint security policies in Microsoft Intune.
