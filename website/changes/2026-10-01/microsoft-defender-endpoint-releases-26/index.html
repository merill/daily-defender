Microsoft Defender Endpoint Releases

1 October 2026Generally available+21 / −0 lines

In brief

The documentation now covers centrally scheduled Linux antivirus scans through managed JSON and Defender Portal policies, expanded detection of critical Node.js, Python, and Java libraries, a libcurl 8.20.0 security update, and Windows Antivirus August 2026-2 details and fixes.

What Defender admins need to know

Administrators can use the documented Linux policy settings to schedule scans centrally and should review the updated release and security information. No mandatory action is stated.
