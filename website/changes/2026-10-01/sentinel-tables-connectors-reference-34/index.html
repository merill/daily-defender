In brief

The reference now lists CiscoMerakiFileScannedEvents_CL and changes F5Telemetry_LTM_CL and RFI_PlaybookAlertResults_V2_CL from No/No to Yes/Yes in the two status columns.

What Defender admins need to know

Administrators should use the updated reference when checking these connector tables and their documented statuses.
