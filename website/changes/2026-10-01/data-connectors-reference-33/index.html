Data Connectors Reference

1 October 2026Feature update+6 / −5 lines

In brief

The Cisco Meraki connector now documents File Scanned detections and the `CiscoMerakiFileScannedEvents_CL` table. F5Telemetry LTM and RFI Playbook Alert Results tables are marked supported, and workspace transform DCR support is documented.

What Defender admins need to know

Administrators can account for File Scanned data in Microsoft Sentinel and use the documented DCR support when configuring data transformations.

The Cisco Meraki connector allows you to easily connect your Cisco Meraki organization events (Security events, Configuration ChangesChanges, API Requests, and API Requests)File Scanned detections) to Microsoft Sentinel. The data connector uses the Cisco Meraki REST API to fetch logs and supports DCR-based ingestion time transformations that parses the received data and ingests into ASIM and custom tables in your Log Analytics workspace. This data connector benefits from capabilities such as DCR based ingestion-time filtering, data normalization.

In addition to the ASIM-normalized events, this connector also ingests Cisco Meraki Dashboard inventory and wireless security data into custom tables - Organizations, Network Clients, Organization Networks, and wireless Air Marshal (rogue access point) events, and File Scanned events.
