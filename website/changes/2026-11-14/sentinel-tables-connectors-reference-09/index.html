Sentinel Tables Connectors Reference

14 November 2026Retirement+17 / −11 lines

In brief

The connector reference now marks the older Exchange Security Insights entries as deprecated and adds Azure Monitor entries. It also adds Menlo, Miro, QCrypton, and RedRays mappings and changes Cisco SD-WAN support flags to Yes.

What Defender admins need to know

Review connector and table references, particularly any use of the deprecated Exchange Security Insights entries. No migration deadline or mandatory change is stated.
