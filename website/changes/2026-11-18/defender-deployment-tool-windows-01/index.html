Endpoint protection

Defender Deployment Tool Windows

18 November 2026Feature updateAction required+15 / −7 lines

In brief

The page now states that online connections require TLS 1.2 and that proxy use during offboarding must be supplied with `-Proxy`. It also documents proxy selection order on Windows Server 2008 R2 SP1 and updates the `-Passive` description.

What Defender admins need to know

If you use a proxy, pass it with `-Proxy` during offboarding and, where applicable, onboarding. Ensure the tool’s connections support TLS 1.2.
