In brief

What Defender admins need to know

Administrators following the article should use the updated Microsoft Defender naming when locating Settings > Identities > Adjust alert thresholds; no configuration change is specified.

Adjust alert thresholds - Microsoft Defender for Identity | Microsoft Learn

This article describes how to configure the number of false positives by adjustingAdjust thresholds for specific identity security alerts in Microsoft Defender for Identity alerts.to reduce false positives.

Some Defender for Identityidentity security alerts rely on learning periods to build a profile of patterns, and then distinguish between legitimate and suspicious activities. Each alert also has specific conditions within the detection logic to help distinguish between legitimate and suspicious activities, such as alert thresholds and filtering for popular activities.

Use the Adjust alert thresholds page to customize the threshold level for specific alerts to influence their alert volume. For example, if you're running comprehensive testing, you might want to lower alert thresholds to trigger as many alerts as possible.

To define your alert thresholds:

  1. In Microsoft Defender, go to Settings > Identities > Adjust alert thresholds.

  2. Locate the alert where you want to adjust the alert threshold and select the threshold level you want to apply.

    • High is the default value, and applies standard thresholds to reduce false positives.
    • Medium and Low thresholds increase the number of alerts generated by Defender for Identity.Defender.

    When you select Medium or Low, details are bolded in the Information column to help you understand how the change affects the alert behavior.

  3. Select Apply changes to save changes.

Switch to Recommended test mode

The Recommended test mode option is designed to help you understand all Defender for Identity alerts, including some related to legitimate traffic and activities so that you can thoroughly evaluate Defender for Identityidentity threat detection as efficiently as possible.

If you recently deployed Defender for Identity and want to test it, select the Recommended test mode option to switch all alert thresholds to Low and increase the number of alerts triggered.
