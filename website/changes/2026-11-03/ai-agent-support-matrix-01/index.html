AI agent discovery support

Local AI agent discovery is generally available on supported Windows and macOS devices, except for the preview scenarios identified in this section. For minimum Defender versions and other requirements, see Discover local AI agents.

AI agent discovery identifies local AI agents and their configured Model Context Protocol (MCP) servers on onboarded devices. The Name values in these tables correspond to the Name column in the AgentsInfo advanced hunting table. The Vendor values correspond to RawAgentInfo.localAgentMetadata.vendor.

Discovery is activity based.depends on the agent type. A running process doesn't imply that the user submitted prompts or successfully accessed an agent after it observes agent activity on an onboarded device.AI service. Extension inventory discovery doesn't require the extension to run. Installing an agent doesn't by itself guarantee that the agent appears in the local AI agent inventory. A checkmark in the Discovers MCP column indicates that Defender reports remote MCP server data in McpServers and local MCP server data in RawAgentInfo.localAgentMetadata.localMcps. A dash indicates that MCP server configuration discovery isn't documented for that combination.

For runtime protection support, see AI agent runtime protection support.
