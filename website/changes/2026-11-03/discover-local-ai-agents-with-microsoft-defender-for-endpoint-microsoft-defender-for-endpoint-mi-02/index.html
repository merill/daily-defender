3 November 2026Feature updateAction required+31 / −10 lines

In brief

The documentation now states that observing an agent process can create an inventory entry without a prompt or service permission, and that discovery does not prove active use or successful access. It adds minimum Defender versions and unified RBAC permissions for viewing inventory and the attack surface graph.

What Defender admins need to know

Update Defender to the documented minimum versions and verify the required Security for AI and Exposure Management permissions for administrators who need to view this data.

Discover local AI agents with Microsoft Defender for Endpoint - Microsoft Defender for Endpoint | Microsoft Learn

Microsoft Defender discovers supported AI agents and their MCP servers after it observes agent activity on onboarded devices anddevices. It surfaces themthese agents in the AI agent inventory and advanced hunting. An installed agent might not appear until Defender observes agent activity. To learn more about local AI agent discovery,how discovery works, see the discovery overview. For agent and MCP coverage by agent, operating system, and MCP server configuration, see the support matrix.

For process-based discovery, observing the agent's process running can be enough for an inventory entry. The user doesn't need to submit a prompt or have permission to use the agent's service. Discovery doesn't prove active use or successful access to an AI service.

In this article, you learn how to view discovered agents in the inventory, review their configuration and risk, explore their relationships with devices and identities, and investigate agent presence using advanced hunting.

Note

Local AI agent discovery on macOS is in preview.

Prerequisites

  • Your environment is in the commercial cloud. Sovereign and national clouds aren't supported.
  • Your organization has a Microsoft Defender for Endpoint Plan 2 license. For more information, see Licensing.
  • Your devices are onboarded to Microsoft Defender for Endpoint.
  • Your devices run a supported version of Windows or macOS,macOS and Microsoftmeet the minimum Defender Antivirus is updated with current monthly platform and engine updates.version requirements in the following table.
  • Microsoft Defender Antivirus is running in active mode on your devices, with real-time protection enabled.enabled, except for the Windows and macOS VS Code extension inventory entries described in the following note.
Operating systemMinimum Defender version
WindowsMicrosoft Defender Antivirus platform version 4.18.26090.9 (2609) or later.
macOSMicrosoft Defender for Endpoint version 101.26072.0017 or later.

Note

On Windows and macOS, agent inventory discovery for the VS Code extensions marked with footnote 1 in the support matrix uses an onboarded, running, and reporting Defender for Endpoint client. The client periodically collects installed extension data. This inventory collection doesn't require antivirus active mode or the extension to run. MCP server configuration discovery still requires antivirus active mode and real-time protection. This exception doesn't indicate runtime protection support. The macOS extension entries remain in preview.

Keep Defender and its security intelligence up to date. On Windows, install current monthly platform and engine updates.

You don't need additional deployment, configuration, or scripts beyond the device onboarding requirements. If the device meets all of the prerequisites, agent discovery begins automatically.

Microsoft 365 E5 and Microsoft 365 E7 both include Microsoft Defender for Endpoint Plan 2. If your organization has Microsoft Defender for Endpoint Plan 2 without Microsoft 365 E7 or Microsoft Agent 365, you can discover local AI agents, view the inventory, and query agents in advanced hunting, but the risk level, risk indicators, and security recommendations aren't available.

Permissions

To view the local agent inventory with Microsoft Defender unified RBAC, make sure your role and its assignment include:

  • Permission:Security operations > Security data > Security data basics (Read).
  • Users: Your account, or a Microsoft Entra security group that includes your account.
  • Data source:Security for AI.

For role setup steps, see Create custom roles with Microsoft Defender unified RBAC.

To view the attack surface graph for discovered agents, your role must also include Security posture > Posture management > Exposure Management (Read), with Microsoft Security Exposure Management selected as a data source.
