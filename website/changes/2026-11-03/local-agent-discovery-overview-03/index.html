Local Agent Discovery Overview

3 November 2026Feature updateAction required+8 / −8 lines

In brief

The documentation now distinguishes process-based discovery from VS Code extension collection on Windows and macOS. It also states that MCP server configuration discovery requires antivirus active mode and real-time protection, and removes the macOS preview note.

What Defender admins need to know

Ensure onboarded clients are running and reporting. Enable antivirus active mode and real-time protection if MCP server configuration discovery is required.
