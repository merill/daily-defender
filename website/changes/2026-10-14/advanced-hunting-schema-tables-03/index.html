Advanced Hunting Schema Tables

14 October 2026Doc update+1 / −2 lines

In brief

The schema page no longer labels AgentsInfo as Preview and no longer lists AIAgentsInfo.

What Defender admins need to know

No administrator action is required; update references if you use this schema list.
