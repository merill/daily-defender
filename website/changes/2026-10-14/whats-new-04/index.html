Whats New

14 October 2026Doc update+2 / −2 lines

In brief

The What's new entries for the preview AgentsInfo and AIAgentsInfo advanced hunting tables now show table names as inline code instead of linked text.

What Defender admins need to know

Administrators reviewing these entries will need to use the surrounding documentation navigation rather than the removed inline links.

Summaries are generated from the documentation change itself.

The comparison below shows only the changed extract. Use the full-page view for complete context.

- The [`CloudAuditEvents`](advanced-hunting-cloudauditevents-table) table contains information about cloud audit events for various cloud platforms protected by the organization's Microsoft Defender for Cloud.
- The [`CloudDnsEvents`](advanced-hunting-clouddnsevents-table) table contains information about DNS activity events from cloud infrastructure environments.
- The [`CloudProcessEvents`](advanced-hunting-cloudprocessevents-table) table contains information about process events in multicloud hosted environments.
  • (Preview) The AgentsInfo table in advanced hunting is now available in preview. The AIAgentsInfoAIAgentsInfo table is transitioning to this new table, which provides a unified schema that supports agent inventory and governance for all agent types, including Copilot Studio, Microsoft Foundry, Microsoft 365 Copilot, third-party, and endpoint-discovered agents. Microsoft Agent 365 customers should use the AgentsInfo table today. The AIAgentsInfo table remains accessible until July 1, 2026. Update your queries to use AgentsInfo before this date. For more information, see Advanced hunting schema - Naming changes.
