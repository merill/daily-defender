Attack Simulation Training Insights

14 October 2026Doc update+1 / −1 lines

In brief

The documentation now refers to automated inspection of the simulation payload in the Clicked Message Link entry, replacing wording about non-Microsoft filtering services.

What Defender admins need to know

Use the updated description when interpreting attack simulation results. No administrator action is required.

Summaries are generated from the documentation change itself.
