October 2026

New Defender for Identity security alerts

The October announcement includes the following new alerts:

New alerts related to Entra ID:

  • Suspicious sign-in via Temporary Access Pass

New alerts related to Active Directory:

  • Kerberos privilege escalation using a diamond ticket
  • Malicious Kerberos activity and CVE-2025-33073 exploitation attempt
  • Malicious request of Data Protection API (DPAPI) master key
  • Possible data exfiltration over DNS
  • Suspicious Active Directory Certificate Services (AD CS) certificate request
  • Suspicious Active Directory Certificate Services (AD CS) machine certificate issuance abuse (ESC8)
  • Suspicious Active Directory Certificate Services (AD CS) machine certificate issuance over RPC (ESC11)
  • Suspicious Active Directory Certificate Services (AD CS) misconfigured certificate template abuse (ESC1)
  • Suspicious Certificate Authority (CA) certificate and private key theft
  • Suspicious Kerberos PKINIT authentication (AS-REQ)
  • Suspicious Kerberos ticket authorization data

New alerts related to other identity providers:

  • Anomalous volume of failed Okta authentication attempts
  • Multifactor authentication method added for a privileged Okta account
  • Okta access or refresh token grant from a risky context
  • Okta anomalous privileged account authentication
  • Okta consent grant from a risky context
  • Password of a privileged Okta account was reset by another account
  • Secondary identity provider added in Okta

General availability of sensor v3.x activation without Defender for Endpoint

Defender for Identity sensor v3.x activation without Defender for Endpoint is now generally available for eligible domain controllers running Windows Server 2019 or later. This activation method supports only new sensor v3.x deployments on eligible domain controllers without an existing Defender for Identity sensor. Sensor v2.x migration isn't supported. For more information, see Activate the Defender for Identity sensor.
