Cloud and workloads

Data Security Posture Prepare

8 November 2026Feature update+8 / −6 lines

In brief

The documentation updates the AWS S3 and GCP supported-region lists and adds explicit lists of unsupported AWS S3 and GCP regions.

What Defender admins need to know

Administrators should use the revised regional coverage lists when assessing AWS S3 or GCP resource support. No action is required by this change alone.
