Microsoft Defender Endpoint Releases

21 October 2026New feature+23 / −1 lines

In brief

The macOS 101.26082.0012 release adds EDR support for configuring AI agent runtime protection, plus Bluetooth permission and antivirus health reporting improvements, accessibility updates, reliability fixes, and performance fixes.

What Defender admins need to know

MacOS administrators should review the new EDR configuration support and updated health reporting when assessing this release.
