Sap Btp Solution Overview

21 October 2026New feature+10 / −3 lines

In brief

The Microsoft Sentinel Solution for SAP BTP covers all SAP BTP services that log security-relevant events to the SAP Audit Log Management service. See SAP's official documentation for the latest list of supported services and logged events.

The solution also includes a separate preview connector for the SAP Application Vulnerability Report Service. It ingests vulnerability findings for custom apps deployed on SAP BTP. You can use these findings with BTP audit activity to investigate vulnerable applications and related security events.

Among the supported services are, but not limited to:

  • SAP Cloud Integration - Integration Suite: A service that enables you to connect different SAP applications and systems, both on-premises and in the cloud, to facilitate data exchange and integration processes.
  • SAP Build Work Zone: A unified point of access to SAP applications (such as SAP S/4HANA), custom-built, and third party applications and extensions, both on the cloud and on premise.
  • SAP Datasphere - SAP Business Data Cloud: A cloud-based data management and analytics platform that enables you to collect, store, process, and analyze large volumes of data from various sources, including SAP and non-SAP systems.
  • SAP AI Core: A service that allows you to build, deploy, and manage AI models and applications on SAP BTP, leveraging machine learning and deep learning techniques to enhance business processes and decision-making.
  • SAP Event Mesh: A service that enables event-driven architecture and real-time data processing on SAP BTP, allowing you to create, publish, and subscribe to events acrossbetween different applications and systems.

Solution architecture

  • The SAP BTP connector, which allows you to connect your BTP subaccounts and global account to Microsoft Sentinel via the Audit Log service for SAP BTP API. Learn how to install the solution and data connector.
  • Built-in analytics rules for identity management and low-code application development scenarios using the Trust and Authorization Provider and Business Application Studio (BAS) event sources in BTP.
  • The Application Vulnerability Report for SAP BTP connector (Preview), which ingests vulnerability findings from the SAP Application Vulnerability Report Service. Configure this connector separately from the audit log connector. Learn how to configure the Application Vulnerability Report connector.
  • A preview analytics rule that detects critical vulnerability findings in custom apps, and an Application Vulnerabilities workbook tab with a vulnerability posture KPI. For details, see the security content reference.
  • The BTP activity workbook, which provides a dashboard overview of subaccounts and a grid of identity management events. \ No newline at end of file
