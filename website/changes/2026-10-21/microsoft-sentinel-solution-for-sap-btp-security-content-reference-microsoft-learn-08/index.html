Microsoft Sentinel Solution for SAP BTP - security content reference | Microsoft Learn

21 October 2026New feature+23 / −8 lines

In brief

The documentation now describes an optional Application Vulnerabilities workbook tab and an analytics rule correlating SAP Application Vulnerability Report Service findings with BTP audit events. The rule detects custom apps with open high or critical vulnerabilities, using a default CVSS threshold of 7.0 and a 14-day evaluation window.

What Defender admins need to know

Administrators can monitor SAP application vulnerability posture alongside BTP activity. The rule requires data from both the SAP BTP AVL and SAP BTP audit events connectors.

Microsoft Sentinel Solution for SAP BTP - security content reference | Microsoft Learn

This article detailsUse this reference to review the security content available for the Microsoft Sentinel Solution for SAP BTP.

Available security content currently includes a built-in workbook and analytics rules. You can also add SAP-related watchlists to use in your search, detection rules, threat hunting, and response playbooks.

Learn more about the solution.

The workbook also includes an optional Application Vulnerabilities tab for SAP Application Vulnerability Report Service findings. The Overview tab includes a vulnerability posture KPI to help you monitor these findings alongside BTP activity.

For more information, see Tutorial: Visualize and monitor your data and Deploy Microsoft Sentinel Solution for SAP BTP.
