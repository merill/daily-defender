Offboard Machines

21 October 2026Feature update+58 / −43 lines

In brief

The documentation now covers Windows, Linux client and server, macOS, Android, and iOS offboarding. It also distinguishes subscription-wide Azure server offboarding from manual individual-server offboarding and clarifies that offboarding does not uninstall software.

What Defender admins need to know

Administrators can follow OS-specific procedures and should choose the correct server path. Turning off Defender for Servers offboards eligible Azure servers automatically, while software removal requires separate uninstall steps.

    Manual endpoint offboarding

    Use a supported endpoint tool to offboard individual servers, including manually onboarded on-premises servers, or to complete an intended endpoint change after reviewing the automatic flow's result.

    Follow one of the methods below. Manual endpoint offboarding isn't a substitute for changing Defender for Servers coverage.

    Download an offboarding package

    Open the Offboarding page in Microsoft Defender. Use an account authorized to download the package, and then follow the relevant method's operating-system and package selections.

    Download a current package for the correct tenant, check its expiration, and store it securely. Package formats and validity periods differ by method.

    For local-script or Configuration Manager offboarding, select the Windows version group specified in that method's instructions. The generic Windows option opens the separate Defender deployment tool workflow, not the version-specific package workflow.

    Offboard MacMacOS devices

    In the following procedure, steps 1 and 2 are optional if you do not want to see these devices that areas retired in the "Device inventory" for 180 days.

    1. Create a device tag, and name the tag decommissioned. Assign the tag to the Mac devices that you want to offboard from Defender for Endpoint.

    2. Create a Device group and name it something like, Decommissioned Mac. Assign this tag to an appropriate user group.

    3. Remove policies for Tamper Protection. See Set preferences on Mac: Tamper protection, or turn off tamper protection by using local configuration.

    4. In the Microsoft Defender portal, navigate to, System > Settings > Endpoints > Device management > Offboarding. Select macOS in Step 1, then choose your preferred deployment method, and select Download package to download the offboarding package.

      Or, if you're using a non-Microsoft device management solution, disable integration with Defender for Endpoint.

    5. Uninstall the Defender for Endpoint app on Mac devices.

    6. Remove Mac devices from the group for system extension policies if an MDM was used to set them.

    Offboard Android or iOS devices

    To offboard an Android or iOS device, uninstall the Microsoft Defender app on the device.

    Offboard cloud and on-premises servers

    Offboard an Azure environment in one step by turning off Defender for Servers for the subscription. Eligible servers are offboarded automatically, without running an offboarding package on each server. To offboard only selected servers, use manual offboarding.
