Detect use of vulnerable SAP BTP custom apps (Preview)

The SAP BTP solution adds an analytics rule that correlates SAP Application Vulnerability Report findings with BTP audit logs to detect use of custom apps with open high or critical vulnerabilities. The rule identifies interactive XSUAA logins that match a vulnerable app and application audit events in the same subaccount, Cloud Foundry organization, and space. It uses a default CVSS threshold of 7.0 and a 14-day finding lookback. For details, see SAP BTP security content.
