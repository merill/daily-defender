Whats New In Microsoft Defender Endpoint

26 November 2026New feature+3 / −1 lines

In brief

The page now documents Active Directory domain filtering in device inventory and server-side filtering for export assessment APIs using the `$filter` parameter. The API filtering capability is marked Preview; domain filtering is marked GA.

What Defender admins need to know

Administrators can narrow device investigations by domain, while API users can reduce retrieved data and transfer volumes. No action is required.
