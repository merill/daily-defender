24 November 2026Doc update+15 / −13 lines

In brief

The reference now includes DataverseActivity, PowerAutomateActivity, and PowerPlatformAdminActivity. Delinea, Exchange Security Insights, and Snowflake table entries now show Yes/Yes instead of No/No in the reference indicators.

What Defender admins need to know

Use the updated reference when verifying connector and table support. No administrator action is specified.
