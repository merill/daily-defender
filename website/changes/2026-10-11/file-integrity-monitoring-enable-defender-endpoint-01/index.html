File Integrity Monitoring Enable Defender Endpoint

11 October 2026Feature update+4 / −3 lines

In brief

The documentation now specifies that Security Admin and Owner roles on the subscription containing the Log Analytics workspace are required to enable, disable, or change File Integrity Monitoring. Security Reader can view results.

What Defender admins need to know

Review role assignments and subscription scope when granting File Integrity Monitoring access.
