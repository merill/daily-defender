App Governance App Policies Create

25 November 2026Feature update+8 / −4 lines

In brief

Administrators cannot create policies using the Last used condition. Evaluation of existing policies using it is paused, so they do not generate alerts or execute governance actions; their configurations remain unchanged.

What Defender admins need to know

Policies using Last used may create monitoring and enforcement gaps while evaluation is paused. No required configuration change is stated.

Summaries are generated from the documentation change itself.

Documentation change

The comparison below shows only the changed extract. Use the full-page view for complete context.

For apps connected to Microsoft Entra ID, create app policies from provided templates that can be customized, or create your own custom app policy.

Note

You temporarily can't create app governance policies that use the Last used condition. Evaluation of existing policies that use this condition is also paused, so affected policies don't generate alerts or execute governance actions. Existing policy configurations remain unchanged, and policy evaluation will resume when normal operation is restored.

  1. To create a new app policy for Microsoft 365 apps, go to Microsoft Defender > App governance > Policies > Microsoft 365.

    For example:
