Advanced Hunting Identityinfo Table

19 November 2026Doc update+14 / −7 lines

In brief

The documentation now lists IdentityId, SourceProvider, RiskScore, RiskScoreUpdateTime, and TimeGenerated, and updates descriptions or data types for Timestamp, State, and UserAccountControl.

What Defender admins need to know

Administrators using IdentityInfo advanced-hunting queries should account for the added fields and updated schemas when interpreting or writing queries. No administrator action is stated.
