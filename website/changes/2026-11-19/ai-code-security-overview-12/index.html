Ai Code Security Overview

19 November 2026Doc update+44 / −10 lines

In brief

The page now lists Azure region identifiers, notes that Microsoft Foundry integration requires Azure OpenAI Responses API support, and identifies UAE as CLI-only. It also documents optional MAI Cyber model integration and its available Foundry regions.

What Defender admins need to know

Admins planning Foundry integration should verify regional support. MAI Cyber is optional for standard MDASH scans.
