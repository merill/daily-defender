The documentation now covers including or excluding custom detections from Microsoft Defender XDR correlation on a per-rule basis. Custom detections are included by default; exclusions create predictable single-alert incidents when no matching grouping rule applies.

What Defender admins need to know

Administrators should note the required permissions and that no tenant-level custom detection setting is available. No action is required.

  • Custom detections - You need permission to manage the custom detection rule. For more information, see Required permissions for managing custom detections.

Configure custom detection correlation (public preview)

Include or exclude each custom detection from correlation. Existing and new custom detection rules are included in correlation by default. Inclusion is the recommended setting because it helps combine related activity into a broader incident story.

On the custom detection rule details page, use Include or exclude from correlation to select one of these settings:

  • Include in correlation - Alerts participate in Microsoft Defender XDR correlation.
  • Exclude from correlation - Alerts bypass standard Microsoft Defender XDR correlation and create predictable, single-alert incidents when no matching incident alert-grouping rule applies.

Exclusion can help when a detection scenario requires predictable incident creation. For example, use exclusion to:

  • Trigger automation or playbooks when an incident is created.
  • Route cases to a specific team based on the detection.
  • Support compliance or escalation workflows that require standalone incidents.

Custom detection correlation is configured per rule. A tenant-level correlation setting isn't available for custom detections.

Important

Incident alert-grouping rules remain the final authority. If a matching alert-grouping rule applies, it determines the final incident-grouping behavior.

How analytics rule exclusion works

Depending on your tenant's settings, you can exclude all or only specific analytics rules from correlation.
