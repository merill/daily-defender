Custom Detection Manage

13 October 2026Public preview+3 / −3 lines

In brief

The documentation now states that custom detections are included in correlation by default and have a per-rule option to include or exclude them.

What Defender admins need to know

Administrators can use the per-rule correlation setting when managing custom detections; no required action is stated.
