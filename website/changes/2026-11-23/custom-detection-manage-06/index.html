Edit alert grouping (preview)

Note

Alert grouping for custom detection rules is in preview.

To change alert grouping for a custom detection rule, select Edit on the rule details page, then go to Incident settings and expand Alert grouping. For configuration options and limits, see Alert grouping.

View and manage triggered alerts

In the rule details screen (Investigation & response > Detection > Custom detection rules > [Rule name]), go to Triggered alerts, which lists the alerts generated by matches to the rule. Select an alert to view detailed information about it and take the following actions:
