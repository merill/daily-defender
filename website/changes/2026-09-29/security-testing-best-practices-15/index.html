Security Testing Best Practices

29 September 2026Feature updateAction required+4 / −4 lines

In brief

The guidance now says sensor v2.x deployments should configure a Directory Service Account for full security coverage. A DSA is required to access the DeletedObjects container and for certain cross-domain and non-domain-controller scenarios.

What Defender admins need to know

Review sensor deployments and configure a DSA where required to maintain full coverage and access.
