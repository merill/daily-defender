Directory Service Accounts

29 September 2026Feature update+4 / −2 lines

In brief

The documentation now specifies that a directory service account (DSA) is required for the listed features and functionality when using sensor v2.x.

What Defender admins need to know

Administrators should apply this requirement based on the sensor version deployed.
