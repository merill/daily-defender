Sentinel Integration Guide

29 September 2026Doc updateAction required+1 / −0 lines

In brief

The guide now states that, after publishing a CCF data connector solution to Azure public cloud, publishers must enable Azure Government for the plan in Partner Center.

What Defender admins need to know

Administrators publishing these solutions for Azure Government should enable the plan in Partner Center after public-cloud publication.
