Disable Sql On Machines

29 September 2026Doc update+5 / −5 lines

In brief

The procedure now uses revised wording for the outcome, Azure portal navigation, and Databases plan controls. It states that disabling the plan stops SQL alerts and recommendations for selected machines.

What Defender admins need to know

Administrators can use the updated navigation and control labels when following this procedure.
