Sap Deploy Troubleshoot

30 October 2026Doc update+1 / −1 lines

In brief

The troubleshooting guidance covers manually calling the Data Collector iFlow with the affected startTimeUTC and endTimeUTC values. This recovery is separate from automatic retries and requires the source logs to remain available.

What Defender admins need to know

Administrators can use this guidance to selectively recover previously failed windows; no configuration change is required.

  1. Review the SAP Cloud Integration message processing logs. Identify the affected SAP system (SID), the failed UTC collection window, and the reported error.

  3. Allow automatic retries to recover the failed window, and verify that the expected records for that SID and original event-time interval arrive in the relevant SAP log table.
