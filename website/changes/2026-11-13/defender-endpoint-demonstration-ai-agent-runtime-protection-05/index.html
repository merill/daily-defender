Defender Endpoint Demonstration Ai Agent Runtime Protection

13 November 2026Feature update+15 / −26 lines

In brief

The demonstration guide now uses a support matrix for inspection methods, agent modes, and minimum versions. It distinguishes agent-native inspection (`AiAgentProtection`) from network inspection (`AiAgentNetworkInspection`), removes Beta Channel update configuration steps, and adds known-issues guidance.

What Defender admins need to know

Administrators testing the capability should check the support matrix and configure the setting for the inspection method being tested. No action is required for administrators not running the demonstration.

Run the demonstration

  1. Open an elevated PowerShell session and verify that the platform and engine update channels are set to the Beta Channel:

    Get-MpPreference | Select-Object PlatformUpdatesChannel, EngineUpdatesChannel

  2. Close the elevated PowerShell session and any existing agent or terminal sessions. Open a new terminal.

  3. Start a new session in a supported local AI agent.
