Azure Storage Blob Connector Troubleshoot

24 October 2026Doc update+16 / −1 lines

In brief

The troubleshooting article now explains how to assign Storage Blob Data Reader and Storage Queue Data Contributor roles to the Sentinel service principal, and adds guidance for Event Grid storage queue permission errors.

What Defender admins need to know

Administrators troubleshooting connector authorization failures can use the new role-assignment and Event Grid permission guidance.

  1. Verify that the service principal has the Storage Blob Data Reader role on the storage accounts hosting the blob container.
  2. Verify that the service principal has the Storage Queue Data Contributor role on the storage accounts hosting the message queues.

Steps to add roles to the service principal on the storage accounts:

  1. Select Add Connection. Under Connection configuration, copy Sentinel azure storage enterprise application - service principal ID.
  2. On the storage account, open Access Control (IAM) → Add role assignment. Assign Storage Blob Data Reader and Storage Queue Data Contributor to that service principal.
