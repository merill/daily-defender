In brief

The article no longer recommends using the EOSDate column in Advanced Hunting. It now directs administrators to the end-of-support software guidance and Microsoft Defender for Endpoint vulnerability management to track remediation.

What Defender admins need to know

Administrators with outdated agents should follow the updated remediation guidance to avoid service disruption.
