Mdash Foundry Integration

27 October 2026Feature update+6 / −2 lines

In brief

The integration documentation now labels MAI Cyber (Preview) as the recommended scan configuration and replaces MAI-Cyber-1-Flash with MAI-Cyber-1.1-Flash. Four additional reference links were also added.

What Defender admins need to know

Administrators configuring MAI Cyber should use the newly listed model name and review the updated deployment guidance.
