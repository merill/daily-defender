Mdash Foundry Integration

20 November 2026Doc updateAction required+121 / −17 lines

In brief

The page now documents the three required standard models and the optional recommended MAI-Cyber-1.1-Flash configuration. It also adds Azure CLI deployment steps and specifies Global Standard as MAI Cyber’s supported deployment type.

What Defender admins need to know

Administrators must deploy and verify the three standard models before running scans. To use MAI Cyber, deploy it once through Azure CLI; portal deployment is not supported.

    Deploy MAI Cyber using Azure CLI

    To deploy the MAI Cyber model, complete the following steps.

    1. Open Azure CLI

    Open a terminal with Azure CLI installed or use Azure Cloud Shell.

    Sign in to your Azure account if you haven't already:

    az login

    2. Select your Azure subscription

    Run the following command, replacing <SUBSCRIPTION_ID> with the subscription that contains your Microsoft Foundry resource:

    az account set --subscription <SUBSCRIPTION_ID>

    3. Deploy the MAI Cyber model

    Run the following command, replacing the resource group and Foundry resource name with your values:

    az cognitiveservices account deployment create \
  --resource-group <RESOURCE_GROUP> \
  --name <FOUNDRY_RESOURCE_NAME> \
  --deployment-name mai-cyber-flash \
  --model-name MAI-Cyber-1.1-Flash \
  --model-format Microsoft \
  --model-version 2026-10-13 \
  --sku-name GlobalStandard \
  --sku-capacity 1000

    The command uses the following settings:

    ParameterDescription
    --resource-groupThe Azure resource group containing your Microsoft Foundry resource.
    --nameThe name of your Microsoft Foundry resource.
    --deployment-nameThe deployment name, set to mai-cyber-flash.
    --model-nameThe MAI Cyber model, MAI-Cyber-1.1-Flash.
    --model-formatThe model provider format, Microsoft.
    --model-versionThe model version, 2026-10-13.
    --sku-nameThe deployment type, GlobalStandard.
    --sku-capacityThe requested deployment capacity, set to 1000.

    For more information about the command, see az cognitiveservices account deployment create.

    4. Verify the deployment

    After the command completes successfully:

    1. Return to your Microsoft Foundry project.
    2. Navigate to Models > Deployments.
    3. Verify that mai-cyber-flash appears in the deployment list.
