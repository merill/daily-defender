Release Notes

Cloud and workloads

20 October 2026

The procedure now states that direct onboarding affects all eligible existing and future non-Azure servers in the same Microsoft Entra tenant. 20 October 2026

What changes when managing cloud security plans in the Defender portal - Microsoft Defender for Cloud | Microsoft Learn

Cloud and workloads

A new page explains that moving plan management from the Azure portal to the Defender portal changes billing to Defender Workload Units, shifts configuration to tenant, management-group, or subscription scope, and may replace, consolidate, or measure plans differently. Resource-level configurations are not preserved, and migrated settings become view-only in Azure portal.
