Developer and API

A cross-product view of Microsoft Defender changes related to Developer and API.

Latest Developer and API changes

8 September 2026

Data Connector Ui Definitions Reference

Developer and API

The data connector UI definitions reference now uses the corrected relative link to the Create a codeless connector documentation.

4 September 2026

Api List Incidents

Developer and API

The documentation now explains that incident properties, including severity, may change after creation. Applications should poll `lastUpdateTime` and compare current values with retained values; severity cannot be filtered server-side.

4 September 2026

Automate Microsoft Defender for Cloud connector deployment

Developer and API

The page title and heading now explicitly reference Microsoft Defender for Cloud. The publication date and custom authoring metadata were also updated.

4 September 2026

Configure Connector Login Detection

Developer and API

The documentation now highlights that the machine learning algorithm needs 30 days of Windows Security events to establish a user-behavior baseline before detecting incidents.

4 September 2026

Connect apps with API connectors in Microsoft Defender for Cloud Apps

Developer and API

The article now more clearly covers supported connectors, scanning and data collection, connector management, prerequisites, and connector-specific guides. Wording, headings, navigation, and metadata were also updated.

4 September 2026

Connect Mdti Data Connector

Developer and API

The documentation now explicitly identifies intelligence ingested from the Defender Threat Intelligence connector, while updating related links and page metadata.

4 September 2026

Connect Services Api Based

Developer and API

The article now says table names are listed under each connector in the Data connectors reference and adds a Microsoft Entra ID Protection example. Documentation metadata was also updated.

4 September 2026

Connect to Microsoft Sentinel using a Unified Connector

Developer and API

The article now uses updated navigation and permission guidance, identifies the Okta API token explicitly, and warns that deleting a connector stops ingestion, removes its configuration, and cannot be undone.

4 September 2026

Connect your TIP with the upload API (Preview)

Developer and API

The article now identifies the upload API as a preview API, clarifies STIX-supported uploads and prerequisites, renames the configuration section, and updates related links and permission wording.

4 September 2026

Create a pull codeless connector for Microsoft Sentinel

Developer and API

The article distinguishes pull/polling connectors from push connectors and focuses its instructions on connectors that periodically fetch data through APIs. It also links to the Microsoft Sentinel Visual Studio Code extension.

4 September 2026

Create an Azure DevOps connector for agentic code security

Developer and API

Documentation now describes connecting Azure DevOps organizations to Microsoft Defender for repository discovery and remote on-demand agentic code scans, with optional write access for remediation workflows.

4 September 2026

Create custom Microsoft Defender XDR reports using Microsoft Graph security API and Power BI

Developer and API

The article now refers to required RBAC permissions, expands OData, and documents relative lookback and date-parameter queries for Microsoft Graph alert and incident data. It also updates wording and metadata.

4 September 2026

Create pull codeless data connectors using nested API polling

Developer and API

Microsoft Sentinel now documents how to build Codeless Connector Framework pull connectors that chain parent and child REST API calls, including configuration of nested polling in RestApiPoller connection rules.

4 September 2026

Create Push Codeless Connector

Developer and API

The documentation changed “Next steps” to “Related content” and “Getting help” to “Get help.”

4 September 2026

Data Connector Connection Rules Reference

Developer and API

The documented maximum for both `RequestTimeoutInSeconds` and `TimeoutInSeconds` increased from 180 to 300 seconds. Their default values remain 100 and 20 seconds, respectively.

4 September 2026

Data Connector Ui Definitions Reference

Developer and API

Seven screenshot references now use the `isv/media/create-codeless-connector/` path.

4 September 2026

Deploy Data Connector Agent Container

Developer and API

The documentation page for connecting SAP systems to Microsoft Sentinel was deleted, including guidance for both the agent and agentless connector options, prerequisites, and deployment steps.

4 September 2026

Develop Custom Graph Solutions for Microsoft Sentinel

Developer and API

The new guide explains how to build, test, materialize, query, package, and publish notebook-based custom graph solutions using Sentinel data lake tables and Graph Query Language. It also documents prerequisites, permissions, tools, and the preview status.

4 September 2026

Enable API security posture with Defender CSPM

Developer and API

The page now states that disabling the API posture extension offboards all APIs from the Defender CSPM plan and disables API security posture management. It also updates related link text and the Azure free account wording.

4 September 2026

Enable gated deployment for AKS by using the managed cluster API

Developer and API

The gated deployment documentation now provides steps for configuring the managed identity and clarifies that setting the MSI objectId in the identities parameter enables runtime use by the gated deployment agent.

4 September 2026

Graph Visualization

Developer and API

The documentation now explains that only graphs materialized by published graph jobs appear in Graph management, on-demand job graphs are retained for 30 days, scheduled jobs rebuild graphs, and graph queries incur graph-meter charges. It also notes that predefined queries use a default LIMIT clause that can cap visualization results.

4 September 2026

Investigate activities using the API

Developer and API

The article now describes scanning and retrieving large volumes of activity data, clarifies pagination wording, and reorganizes the next-steps links under Related content.

4 September 2026

Investigation graph

The article’s metadata was refreshed, and wording and link formatting were updated in the investigation graph and threat intelligence instructions.

4 September 2026

4 September 2026

Adds documentation for the Grant-DefenderConsent.ps1 PowerShell script, including service-principal provisioning, tenant-wide admin consent, and optional token validation modes.

The guide now states that Microsoft will permanently retire and disable the containerized SAP connector agent on September 14, 2026. It also directs new deployments to the agentless connector and confirms existing analytics rules, workbooks, and playbooks remain functional.
