Microsoft Secure Score: New recommendation to reduce inbound internet exposure

Message CenterMC1358832 on mc.merill.net ↗Stay informed
Vulnerabilities and exposure

Microsoft Secure Score in Microsoft Defender for Endpoint introduces a new default recommendation to reduce unnecessary inbound internet exposure by identifying internet-facing devices. Rolling out from June 2026, it helps admins validate and remediate exposure risks, improving enterprise security posture with no user impact or required configuration.
