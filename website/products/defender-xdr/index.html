Microsoft Defender for Office 365: Updated recipient inclusion logic for threat protection policies

Message CenterMC1546447 on mc.merill.net ↗Stay informed
General

Microsoft Defender for Office 365 will change recipient inclusion logic in threat protection policies from Match all (AND) to Match any (OR) when multiple recipient types are specified. This update, rolling out in December 2026, expands policy scope upon modification but does not auto-convert existing policies.

Attention needed: Your tenant will be auto enabled for the new Microsoft Defender RBAC model

Message CenterMC1537494 on mc.merill.net ↗Major updatePlan for change
Identity protection

Microsoft Defender RBAC will be auto-enabled in your tenant starting December 2026, unifying access management for Defender and Sentinel. Existing roles will be imported for review before activation about 30 days after notification. Adjust roles as needed; opt-out is available post-activation. Other Microsoft service permissions remain unchanged.

Message CenterMC1486293 on mc.merill.net ↗Major updatePlan for change
Email and collaboration

Microsoft is updating the Microsoft Defender for Office 365 Unified RBAC mapping for the Microsoft Entra Security Operator role, removing default access to email threat policies and Tenant Allow/Block List. Rollout starts December 2026. Organizations must manually assign permissions if continued access is needed.

3 November 2026

Microsoft Defender: Expanded URBAC permission support for email content access

Message CenterMC1536045 on mc.merill.net ↗Stay informed
General

Microsoft Defender has expanded Unified role-based access control (URBAC) permissions for email content access to include alerts related to potentially malicious URL clicks. Security analysts with the appropriate permission can now preview and download emails from four alert types, ensuring consistent access across scenarios.
