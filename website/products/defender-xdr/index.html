Latest Microsoft Defender XDR changes

3 September 2026

Custom Detection Rules

Hunting and detection

The supported table list now spells `ABAPAuditLog_CL` correctly, fixing a missing “L.”

3 September 2026

Microsoft Secure Score: New AI-readiness recommendations for device security

Message CenterMC1466750 on mc.merill.net ↗Stay informed
Endpoint protection

Microsoft Secure Score will add four new AI-readiness recommendations for device security in Microsoft Defender for Endpoint, focusing on TPM 2.0, VBS, HVCI, and LAPS. These will help identify and remediate devices lacking key protections, rolling out from early to late September 2026 with no action required to receive them.

3 September 2026

Threat Analytics

Endpoint protection

The documentation now directs users to check the Threat intelligence section when an emailed threat analytics report is missing from Threat analytics.

2 September 2026

Entity Page Device

General

The documentation now specifies that custom activity data mapped from Sentinel to Microsoft Defender XDR must include either HostName plus NTDomain or HostName plus DnsDomain.

2 September 2026

Microsoft Defender for Office 365: Prompt injection protection for email

Message CenterMC1422060 on mc.merill.net ↗Plan for change
Email and collaboration

Microsoft Defender for Office 365 will introduce prompt injection protection for email, detecting and quarantining malicious content targeting AI assistants. Rolling out from July to October 2026, it affects organizations with Defender Plan 2 or Microsoft 365 E5, enabling automatic high-confidence threat quarantine by default with no required action.

1 September 2026

Microsoft Defender XDR: DLP alerts will be set as behaviors by default

Message CenterMC1465771 on mc.merill.net ↗Major updatePlan for change
General

Microsoft Defender XDR will set Microsoft Purview DLP alerts as behaviors by default starting October 12, 2026, reducing alert volume while keeping DLP data accessible in Advanced Hunting and Purview. Administrators can disable this rule to retain DLP alerts in the Defender XDR incident queue.

28 August 2026

Microsoft Defender: Automated investigation and response (AIR) integrated into antivirus with manual triggering removed

Message CenterMC1411577 on mc.merill.net ↗Major updatePlan for change
Endpoint protection

Microsoft Defender for Endpoint will remove manual triggering and the standalone experience of automated investigation and response (AIR) by early September 2026. AIR functions are integrated into always-on antivirus protection. Organizations using AIR in playbooks or scripts must update them before September 1, 2026.

26 August 2026

Microsoft Defender for Cloud Apps: App Governance support for the Cloud Application Administrator role is being retired

Message CenterMC1462464 on mc.merill.net ↗Major updatePlan for change
General

Support for the Cloud Application Administrator role in Microsoft Defender for Cloud Apps' App Governance will retire on September 26, 2026. Organizations must reassign affected administrators to supported roles like Security Administrator to maintain access when URBAC is enabled. Review role assignments by September 25, 2026.

25 August 2026

Microsoft Defender XDR: Unified identity timeline on the Identity page

Message CenterMC1461705 on mc.merill.net ↗Plan for change
Identity protection

Microsoft Defender XDR is enhancing the Identity page's Timeline tab to provide a unified, chronological view of identity-related activities and alerts from multiple Microsoft security sources. Rolling out mid-September to mid-October 2026, it offers improved context, filtering, and automatic updates without changing existing policies. No action is required to enable it.

25 August 2026

Microsoft Defender XDR: Unified response actions across identity accounts

Message CenterMC1461704 on mc.merill.net ↗Plan for change
Identity protection

Microsoft Defender XDR unifies identity response actions across linked accounts, enabling security teams to manage actions like disabling accounts or forcing password changes from one workflow. It supports multiple identity systems and SaaS apps, enhancing response speed and consistency. Rollout begins mid-October 2026 worldwide.

21 August 2026

Microsoft Defender for Office 365: Localized default mark and notify email template

Message CenterMC1387578 on mc.merill.net ↗Stay informed
General

Microsoft Defender for Office 365 will localize the default "Mark and notify" email template based on users' Outlook language settings, improving clarity in user-reported message notifications. Rollout starts June 2026 worldwide, completing by September 2026. No action is required; admins may inform users and review settings.

21 August 2026

Microsoft Edge: Retirement of Windows Information Protection (WIP) and Microsoft Defender Application Guard (MDAG)

Message CenterMC1459132 on mc.merill.net ↗Major updatePlan for change
Endpoint protection

Microsoft Edge will retire support for Windows Information Protection (WIP) and Microsoft Defender Application Guard (MDAG) by late September 2026. Organizations using these on Windows 10 must migrate to Microsoft Purview solutions and Edge's built-in security features, as these capabilities are already removed in Windows 11 version 24H2.

19 August 2026

Tenant will be auto-enabled into Microsoft Defender Unified RBAC

Message CenterMC1457836 on mc.merill.net ↗Major updatePlan for change
Identity protection

Microsoft Defender Unified RBAC will auto-enable on tenants starting late September 2026, completing by December 2026. It unifies access management across Defender and Sentinel workloads, importing existing roles with a 30-day notification period before activation. Opt-out is available post-activation; other Microsoft permissions remain unchanged.

17 August 2026

Microsoft Purview | Data Security Triage Agent Summaries for DLP Alerts in Microsoft Defender XDR

Message CenterMC1255406 on mc.merill.net ↗Major updatePlan for change
General

Microsoft Purview introduces AI-generated summaries and categorizations for DLP alerts within Microsoft Defender XDR, aiding security analysts in triage. The Data Security Triage Agent can be deployed from Defender XDR, with management in Purview. Rollout starts April 2026 (preview) and August 2027 (GA). Existing policies remain unchanged.

14 August 2026

New Defender for Identity health alert for missing domain controller network traffic

Message CenterMC1455017 on mc.merill.net ↗Stay informed
Incidents and response

Microsoft Defender for Identity now includes a health alert for missing domain controller network traffic, helping administrators detect traffic collection issues affecting visibility. The alert appears in sensor health tabs, requires no pre-rollout action, and guides troubleshooting if triggered after rollout. No impact on end users or compliance.

14 August 2026

New Defender for Identity health issue for missing Windows events from a domain controller

Message CenterMC1455016 on mc.merill.net ↗Stay informed
Identity protection

Microsoft Defender for Identity now includes a new sensor health issue, "No Windows events received from domain controller," to alert administrators of missing Windows events. This improves visibility into event collection gaps affecting detections. It is available now, requires no pre-rollout action, and helps identify domain controller issues.

13 August 2026

Action required: Update Microsoft Defender for Endpoint Android App

Message CenterMC1454382 on mc.merill.net ↗Prevent or fix issue
Endpoint protection

Update Microsoft Defender for Endpoint Android to version 1.0.9107.0101 or later by mid-September 2026 to avoid disruption in mobile threat protection due to infrastructure changes. Administrators should verify and update devices and inform users managing their own updates. No other configuration changes are needed.

6 August 2026

Microsoft Defender for Office 365: AIR Investigation Experience Improvements

Message CenterMC1431377 on mc.merill.net ↗Stay informed
General

Microsoft Defender for Office 365's AIR experience will add a manual refresh button, replacing auto-refresh, and simplify investigation names by removing email subjects and UPNs. These changes improve performance, reduce network activity, and support data minimization. No admin action is required, but workflow updates are recommended.

5 August 2026

Microsoft Teams: Report security concerns in Teams meetings

Message CenterMC1446794 on mc.merill.net ↗Plan for change
General

Microsoft Teams will introduce a "Report a meeting" feature starting August 2026, allowing users to report suspicious or malicious activity during meetings. Reports help security teams investigate threats via Microsoft Defender and Teams admin center. The feature is enabled by default, with administrative controls and data collection for security investigations.

5 August 2026

Microsoft Teams: Users can report security concerns in group calls

Message CenterMC1447673 on mc.merill.net ↗Plan for change
General

Microsoft Teams will introduce a "Report a call" feature for group calls, allowing users to report suspicious calls from call history. Administrators can review reports in Teams admin center and Microsoft Defender. The feature rolls out from August to October 2026 and is enabled by default.

3 August 2026

Microsoft Defender for Office 365: Enhancing how we handle promotional mail

Message CenterMC1279093 on mc.merill.net ↗Major updatePlan for change
Email and collaboration

Microsoft Defender for Office 365 will tag promotional emails as “promotions” and can auto-move them to a Promotions folder, learning user preferences over time. Public preview starts mid-April 2026; general availability begins late July 2026. Admins can configure settings, and users can train the system by moving messages.

29 July 2026

Email and collaboration

Microsoft Defender for Office 365 will introduce an opt-in Safe Attachments policy to quarantine emails with password-protected attachments that cannot be scanned. Administrators can control release, users can self-release with passwords, and the feature supports various file types. Rollout begins August 2026 worldwide.
