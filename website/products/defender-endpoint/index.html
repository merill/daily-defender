Latest Microsoft Defender for Endpoint changes

13 November 2026

Ai Agent Support Matrix

Endpoint protection

The matrix now lists Droid CLI, Factory App, Kimi Work, and Replit Agent, and identifies Alibaba Cloud as the provider for Qwen Code Desktop. The page date was also updated.

Endpoint protection

The documentation now specifies that both settings use 0 for Disabled, 1 for Block, and 2 for Audit.

Endpoint protection

The demonstration guide now uses a support matrix for inspection methods, agent modes, and minimum versions. It distinguishes agent-native inspection (`AiAgentProtection`) from network inspection (`AiAgentNetworkInspection`), removes Beta Channel update configuration steps, and adds known-issues guidance.

11 November 2026

Ai Agent Runtime Protection Overview

Endpoint protection

The page now documents inaccurate blocked-alert titles in Audit mode and a Claude Code limitation where tool responses may continue after a Block-mode alert.

11 November 2026

Configure Ai Agent Runtime Protection

Endpoint protection

The documentation now notes that Audit mode may incorrectly report a prompt injection block, and Claude Code may continue processing a tool response after a reported block in Block mode.

10 November 2026

Respond File Alerts

Endpoint protection

The documentation now states that portal downloads use a cloud-backed copy, not the device’s local quarantine. Cloud backup applies to files up to 100 MiB; larger files remain quarantined but cannot be downloaded from the portal. Collect file retrieves the current device path and may fail if quarantine removed the original.

6 November 2026

Microsoft Defender Endpoint Releases

Endpoint protection

The documentation identifies iOS platform version 1.1.82260102, released November 3, 2026, with improved redirected-network reliability on slow or low-bandwidth networks and updated translations for advanced diagnostic settings.

5 November 2026

Microsoft Defender Endpoint Releases

Endpoint protection

The Android release documentation now lists version 1.0.9428.0102, released October 30, 2026. It includes general performance and bug fixes, including a rare initialization crash fix, and refreshes network protection notifications after qualifying network changes.

Endpoint protection

The guidance now states that Linux investigation packages include Microsoft Defender for Endpoint Client Analyzer diagnostics alongside system information, covering installation, configuration, service health, logs, and connectivity.
