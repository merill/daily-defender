Month in brief

Managed Linux scans, server exclusions, and Teams reporting shape October Defender guidance

October’s most actionable content is a set of precise configuration and reference updates. Defender for Endpoint release guidance now documents centrally scheduled Linux antivirus scans through managed JSON and Defender Portal policies; Secure Controlled Configuration lists Windows Server 2022 and 2025 and clarifies local administrator-defined exclusion handling. For eligible Worldwide Defender for Office 365 customers, Teams user reporting is directed to a separate settings page, with related guidance defining report destinations. Sentinel’s connector reference adds Cisco Meraki File Scanned schema details and workspace transform DCR support. Most remaining Defender for Business edits are wording, links, terminology, and navigation cleanup.

  • Endpoint · Endpoint protection
    Defender for Endpoint release guidance documents centralized Linux antivirus scans

    The release page now covers centrally scheduled Linux antivirus scans through managed JSON and Defender Portal policies. It also documents expanded detection of critical Node.js, Python, and Java libraries, the libcurl 8.20.0 security update, and Windows Antivirus August 2026-2 details and fixes. Administrators can use the documented Linux policy settings; the entry states that no mandatory action is required.

  • Endpoint · Endpoint protection
    Secure Controlled Configuration documents Windows Server 2022 and 2025

    The documented device requirement now includes Windows Server 2022 and Windows Server 2025. The guidance also clarifies that local administrator-defined antivirus exclusions are not honored by default and can be enabled through Defender or Intune policy.

  • Office 365 · Email and collaboration
    Teams reporting guidance specifies its settings path and destinations

    The Teams submissions article now points administrators to the Teams user reported settings page and documents Exchange Online PowerShell commands for viewing and configuring report destinations: Microsoft, a reporting mailbox, or both. Administrators can use the revised page and examples to verify or manage Teams reporting.

  • Business · Endpoint protection
    Defender for Business policy guidance spells out priority application

    The revised article states that only the highest-priority applicable policy is applied. Default policy priority remains fixed, while new policies are assigned a priority and move default policies lower. Administrators can use this clarification when reviewing or reordering custom policies.

  • Sentinel · Cloud and workloads
    Sentinel reference adds Cisco Meraki File Scanned data and DCR support

    The Data Connectors Reference now documents File Scanned detections and the CiscoMerakiFileScannedEvents_CL table. It also marks the F5Telemetry LTM and RFI Playbook Alert Results tables as supported and documents workspace transform DCR support for data transformations.

For Defender administrators

Review the Linux policy instructions if centralized scans are needed. For Secure Controlled Configuration, account for the listed server versions and use Defender or Intune policy when local administrator-defined exclusions need to be enabled. Eligible Defender for Office 365 administrators should use the separate Teams reporting page and verify whether reports go to Microsoft, a reporting mailbox, or both. Use the revised policy-order explanation when reordering custom policies, and consult the updated Sentinel references when handling Cisco Meraki File Scanned data or workspace transform DCRs. The supplied entries state no mandatory action for the release notes or general editorial revisions.
