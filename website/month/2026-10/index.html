Month in brief

Advanced Hunting API retirement sets January migration deadline as Teams hunting expands

October was largely documentation maintenance, but several changes have direct operational weight. Microsoft set a January 31, 2027 deadline to move Microsoft Defender for Endpoint and Defender XDR Advanced Hunting API workflows to the Microsoft Graph Security API before the APIs retire. Defender for Office 365 also introduced Teams investigation data and scheduled a Unified RBAC access change, while Defender for Cloud guidance now spells out portal-plan scope, migration effects, and DWU billing.

  • Defender XDR · Hunting and detection
    Advanced Hunting APIs have a firm Graph migration deadline

    Microsoft Defender for Endpoint and Defender XDR Advanced Hunting APIs are scheduled to retire on February 1, 2027. Workflows must be manually migrated to the Microsoft Graph Security API by January 31, 2027, to preserve functionality.

  • Defender for Cloud · Cloud and workloads
    Defender for Cloud portal-plan guidance adds Azure scope and DWU billing

    The updated guidance separates broad cloud-security data support for Azure, AWS, and GCP from onboarding and plan management, which currently support Azure commercial environments only. After migration, plan settings are view-only in the Azure portal, resource-level configurations are not preserved, and billing uses Defender Workload Units.

  • Defender XDR · Email and collaboration
    Security Operator defaults lose Defender for Office 365 policy access

    Starting in November 2026, the Unified RBAC mapping for the Microsoft Entra Security Operator role removes default access to email threat policies and the Tenant Allow/Block List when Unified RBAC is enabled. Manual permission assignment is required to retain access.

  • Defender XDR · Hunting and detection
    MessageContents adds Teams snippets and metadata to Advanced Hunting

    Defender for Office 365 is rolling out a new MessageContents table for Teams messages from late September through mid-November 2026. Authorized analysts can query message snippets and metadata for investigations, subject to specific permissions.

  • Cloud Apps · Cloud and workloads
    Two EWS App Governance detections stop generating alerts

    Cloud Apps guidance now states that, as of October 15, 2026, two EWS-based anomaly detections are retired and no longer generate alerts. Monitoring and triage processes that depend on those detections should be reviewed.

For Defender administrators

Inventory MDE and XDR Advanced Hunting API consumers and complete migration by January 31, 2027. For Defender for Cloud portal-managed plans, verify Azure commercial eligibility, account for non-preserved resource-level settings and Defender Workload Unit billing, and review the resulting Azure-portal view-only state. Before the November RBAC change, manually preserve Security Operator access where Unified RBAC is enabled; validate permissions and procedures for MessageContents and remove dependencies on the retired EWS detections.
