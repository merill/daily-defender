Month in brief

Defender URBAC removes Security Operator email-policy access ahead of December rollout

November’s main administrator-impacting change is a December 2026 Unified RBAC remapping: the Microsoft Entra Security Operator role will lose default access to email threat policies and the Tenant Allow/Block List. A separate permission expansion now covers email-content preview and download for alerts involving potentially malicious URL clicks. Other significant updates clarify local AI-agent discovery boundaries, Defender for Cloud management transfers, and Sentinel query limitations with private endpoints.

  • Defender XDR · Email and collaboration
    Security Operator loses default access to email threat policies and Tenant Allow/Block List

    Starting in December 2026, Microsoft will update the Defender for Office 365 Unified RBAC mapping for the Microsoft Entra Security Operator role, removing default access to email threat policies and the Tenant Allow/Block List. Organizations that need continued access must manually assign permissions.

  • Defender XDR · General
    Email-content permissions now cover potentially malicious URL-click alerts

    Expanded Unified RBAC support includes alerts related to potentially malicious URL clicks. Analysts with the appropriate permission can preview and download emails from four alert types, providing consistent email-content access across those scenarios.

  • Endpoint · Endpoint protection
    Local AI-agent discovery guidance adds version, permission, and evidence boundaries

    The guidance states that observing an agent process can create an inventory entry without a prompt or service permission, while discovery does not prove active use or successful access. It also adds minimum Defender versions and Unified RBAC permissions for viewing inventory and the attack surface graph.

  • Defender for Cloud · Cloud and workloads
    Defender portal transfers can separate plan enablement from full capability management

    The updated procedure describes selecting DWU to move plan enablement and billing to the Defender portal, with an optional Management selection to move all supported cloud security capabilities. Managed in status values show where each environment is managed.

  • Sentinel · Cloud and workloads
    AMPLS private-endpoint restrictions limit Sentinel query experiences

    The Sentinel guidance distinguishes ingestion from querying: Azure Monitor Private Link Scope supports Sentinel data ingestion into Log Analytics, but not queries through Defender portal experiences or Defender APIs when query access is restricted to private endpoints. Disabling public Log Analytics query access also makes the data unavailable to experiences such as Advanced Hunting.

For Defender administrators

Before the December rollout, identify users who depend on inherited Security Operator access and manually assign required permissions where continued access is needed. Confirm that analysts investigating malicious URL-click alerts have the appropriate email-content permissions. For local AI-agent visibility, meet the documented Defender versions and Unified RBAC prerequisites. When transferring Defender for Cloud management, use the Managed in status to verify the result, and account for Sentinel query limitations before restricting Log Analytics access to private endpoints.
