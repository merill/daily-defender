Month in brief

MDE and XDR Advanced Hunting APIs set January 2027 migration deadline

October’s clearest operational deadline is the retirement of the Microsoft Defender for Endpoint and Defender XDR Advanced Hunting APIs on February 1, 2027; workflows must be manually migrated to the Microsoft Graph Security API by January 31. Other consequential changes include Defender for Office 365 permission remapping and Teams hunting data, preview portal-based Defender for Cloud plan management, and new Exposure Management posture and exemption capabilities.

  • Defender XDR · Hunting and detection
    Advanced Hunting API retirement requires a manual Graph Security API migration

    Microsoft Defender for Endpoint and Defender XDR Advanced Hunting APIs retire on February 1, 2027. Organizations must migrate workflows manually to the Microsoft Graph Security API by January 31, 2027, to maintain functionality.

  • Defender for Cloud · Cloud and workloads
    Defender for Cloud preview moves Azure plan management into the Defender portal

    The preview supports global or scoped cloud-security-plan configuration for connected Azure environments. Migration can remove existing resource-level configurations, makes migrated settings view-only in the Azure portal, and uses Defender Workload Units for billing.

  • Defender XDR · Email and collaboration
    Security Operator loses default access to key Defender for Office 365 controls

    Starting in November 2026, Unified RBAC mapping for the Microsoft Entra Security Operator role removes default access to email threat policies and the Tenant Allow/Block List. Administrators must assign the required permissions manually when continued access is needed.

  • Exposure Management · Vulnerabilities and exposure
    Exposure Management previews add Azure posture policies and recommendation exemptions

    Public preview capabilities let administrators evaluate Azure resources against the Microsoft Defender for Cloud baseline, create custom posture policies, and centrally manage accepted-risk recommendation exemptions with lifecycle tracking.

  • Defender XDR · Hunting and detection
    Teams investigations gain a MessageContents hunting table

    Microsoft Defender for Office 365 is introducing the MessageContents table for querying Teams message snippets and metadata. Rollout runs from late September through mid-November 2026 and requires the appropriate analyst permissions, with potential implications for investigation procedures.

For Defender administrators

Inventory and migrate Advanced Hunting API integrations before the January 31 deadline. Before adopting Defender for Cloud portal-based plan management, verify Azure commercial-environment eligibility and account for lost resource-level configurations, Azure portal settings becoming view-only, and Defender Workload Unit billing. With Unified RBAC enabled, manually restore Security Operator access where needed. Review permissions and handling procedures for Teams message-content hunting, and evaluate the Exposure Management previews against governance requirements.
