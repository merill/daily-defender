Month in brief

Defender AIR moves into always-on protection ahead of September 1

August’s consequential Defender changes center on forced transitions: AIR’s manual and standalone workflow is being removed before September 1, Android clients need a minimum build by mid-September, and Unified RBAC plus Cloud Apps and Edge retirements follow through late September. Microsoft Learn updates were chiefly operational, with macOS guidance separating NetExt, antivirus, and EDR causes, adding health and hot-event diagnostics, and warning that antivirus exclusions do not suppress EDR event processing.

  • Defender XDR · Endpoint protection
    AIR’s standalone and manual-triggered workflow ends September 1

    Microsoft Defender for Endpoint will integrate automated investigation and response into always-on antivirus protection and remove manual triggering and the standalone AIR experience by early September 2026. Organizations using AIR in playbooks or scripts must update them before September 1, 2026.

  • Defender XDR · Endpoint protection
    Android app must reach version 1.0.9107.0101

    Infrastructure changes require Microsoft Defender for Endpoint Android version 1.0.9107.0101 or later by mid-September 2026 to avoid disruption in mobile threat protection. Administrators should verify and update devices and inform users who manage their own updates; no other configuration changes are required.

  • Defender XDR · Identity protection
    Unified RBAC auto-enables tenants from late September through December

    Microsoft Defender Unified RBAC will begin auto-enabling tenants in late September 2026 and complete activation by December 2026, importing existing roles after a 30-day notification period. It unifies access management across Defender and Sentinel workloads; an opt-out is available after activation, while other Microsoft permissions remain unchanged.

  • Defender XDR · General
    Cloud Apps retires App Governance support for Cloud Application Administrator

    Microsoft Defender for Cloud Apps App Governance support for the Cloud Application Administrator role retires on September 26, 2026. Review affected assignments by September 25 and reassign administrators to supported roles such as Security Administrator to maintain access when URBAC is enabled.

  • Defender XDR · Endpoint protection
    Edge retires WIP and MDAG support by late September

    Microsoft Edge will retire Windows Information Protection and Microsoft Defender Application Guard by late September 2026. Organizations still using these capabilities on Windows 10 must migrate to Microsoft Purview solutions and Edge built-in security features; both capabilities are already removed in Windows 11 version 24H2.

For Defender administrators

Remediate AIR playbooks and scripts before September 1, 2026, and update Microsoft Defender for Endpoint Android devices to version 1.0.9107.0101 or later by mid-September. Track the Unified RBAC notification and activation window, review Cloud Application Administrator assignments by September 25, and migrate Windows 10 deployments using WIP or MDAG to Microsoft Purview solutions and Edge built-in security features. For macOS troubleshooting, use the revised process-specific diagnostics before broad exclusions or NetExt disablement.
