Month in brief

Defender admins face an Android update deadline, Unified RBAC auto-enablement, and Edge retirements

August’s main administrator work is time-bound: update the Microsoft Defender for Endpoint Android app to version 1.0.9107.0101 or later by mid-September; prepare for Defender Unified RBAC auto-enablement from late September through December; and migrate Windows 10 deployments before Edge retires WIP and MDAG by late September. Microsoft also detailed the Purview Data Security Triage Agent’s AI DLP summaries and clarified domain-versus-wildcard blocking in the Tenant Allow Block List.

  • Defender XDR · Endpoint protection
    Android threat protection requires app version 1.0.9107.0101 by mid-September

    Microsoft Defender for Endpoint Android must be updated to version 1.0.9107.0101 or later by mid-September 2026. Microsoft attributes the deadline to infrastructure changes and warns of disruption to mobile threat protection. Administrators should verify and update devices and inform users responsible for their own updates; no other configuration changes are needed.

  • Defender XDR · Identity protection
    Unified RBAC will auto-enable tenants beginning in late September

    Microsoft Defender Unified RBAC will auto-enable tenants beginning in late September 2026, with activation completing by December 2026. It unifies access management across Defender and Sentinel workloads, imports existing roles, and provides a 30-day notification period before activation. Tenants can opt out after activation; other Microsoft permissions remain unchanged.

  • Defender XDR · Endpoint protection
    Edge retires WIP and MDAG support by late September

    Microsoft Edge will retire support for Windows Information Protection and Microsoft Defender Application Guard by late September 2026. Organizations using these capabilities on Windows 10 must migrate to Microsoft Purview solutions and Edge’s built-in security features. Both capabilities are already removed in Windows 11 version 24H2.

  • Defender XDR · General
    AI-generated DLP triage summaries are coming through Defender XDR

    Microsoft Purview’s Data Security Triage Agent introduces AI-generated summaries and categorizations for DLP alerts inside Microsoft Defender XDR. The agent can be deployed from Defender XDR and managed in Purview. The announcement schedules preview rollout from April 2026 and general availability for August 2027; existing DLP policies remain unchanged.

  • Office 365 · Email and collaboration
    Tenant Allow Block List now separates apex and wildcard domain scope

    The updated Microsoft Defender for Office 365 guidance states that a block entry for contoso.com covers only that domain, while *.contoso.com covers subdomains but not contoso.com itself. To block both the specified domain and its subdomains, administrators must create separate entries for contoso.com and *.contoso.com.

For Defender administrators

Prioritize verifying and updating the Defender for Endpoint Android app, including notifying users who manage their own updates; no other configuration changes are required. Use the 30-day Unified RBAC notification period to review roles that will be imported, with opt-out available after activation. Organizations using WIP or MDAG on Windows 10 should plan migration to Microsoft Purview solutions and Edge built-in security features; those capabilities are already removed in Windows 11 version 24H2. The DLP triage agent is deployed from Defender XDR and managed in Purview, while existing policies remain unchanged. For Tenant Allow Block List entries, blocking a domain and its subdomains requires separate entries for the apex domain and its wildcard, such as contoso.com and *.contoso.com.
