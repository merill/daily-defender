Day in brief

Advanced Hunting API retirement sets January 2027 migration deadline

Microsoft will retire the Defender for Endpoint and Defender XDR Advanced Hunting APIs by February 1, 2027; workflows must be manually migrated to the Microsoft Graph Security API by January 31. The period also brings a rolling Teams message-content table, an Endpoint Linux release with Azure Linux 4 support and socket-bind telemetry, and clearer AKS policy guidance for Defender for Cloud Security Gating.

  • Defender XDR · Hunting and detection
    Advanced Hunting APIs retire on February 1, 2027

    Microsoft Defender for Endpoint and Defender XDR Advanced Hunting APIs are scheduled for retirement by February 1, 2027. Existing workflows must be manually migrated to the Microsoft Graph Security API by January 31, 2027.

  • Defender XDR · Hunting and detection
    Teams message snippets and metadata enter Advanced Hunting

    The new MessageContents table is rolling out in Microsoft Defender for Office 365 Advanced Hunting from late September through mid-November 2026. Authorized analysts can query Teams message snippets and metadata for investigations, subject to specific permissions.

  • Defender for Cloud · Cloud and workloads
    AKS Deny policies can block Security Gating provisioning

    Defender for Cloud guidance now documents that Deny policies targeting AKS managed clusters can produce RequestDisallowedByPolicy during Security Gating provisioning, even for compliant clusters. Administrators can identify the blocking assignment in the Activity Log and coordinate an Audit-mode change or narrowly scoped exemption.

  • Endpoint · Endpoint protection
    October Linux release adds Azure Linux 4 and socket-bind telemetry

    The October 2026 Microsoft Defender for Endpoint Linux release notes list version 101.26091.0004, Azure Linux 4 support, and TCP socket bind telemetry. After gradual rollout, the telemetry will be available in Advanced Hunting through DeviceNetworkEvents.

  • Sentinel · Cloud and workloads
    Sentinel residency guidance revises regional data handling

    The Sentinel residency page now states that processed and configuration data are processed and stored in onboarding destination regions or applicable existing Defender XDR regions. It adds processed-data examples and removes the 21Vianet retirement notice.
